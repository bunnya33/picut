# 浮光 FloatShot · v0.4.5

使用 **Qt 6 Widgets / PySide6** 开发的 Windows 截图、标注、贴图和录屏工具。项目沿用 Snipaste 的常见操作习惯，录屏为新增模块。

## 直接运行

打开 `dist/FloatShot-0.4.5/FloatShot.exe`，或将 `dist/FloatShot-0.4.5-win-x64.zip` 解压后运行其中的 `FloatShot.exe`。

v0.4.5 按参考图提供渐宽实心箭头、等宽实心箭头、渐宽空心箭头和直线，并调整工具栏图标、分隔线、粗细圆点、方向按钮、图形下拉和两排色板。Esc 退出提示居中于截图选区；颜色沿用最近一次选择，粗细、箭头样式、方向和字体等参数分别记忆并保存，首次默认颜色为 RGB(255, 0, 4)。“设置 → 常规与存储”新增操作通知开关，默认关闭，开启后才显示通知。贴图边框及 F3 原位置行为继续沿用。更新前通过旧版托盘菜单“退出”关闭旧进程，再启动新版。

完整功能、操作和仍有差异的项目见 [Snipaste 功能对齐 v0.4.5](docs/Snipaste功能对齐-v0.4.5.md)。本版尚未完整覆盖 Snipaste 专业版，原生分享、虚拟桌面归属管理、系统主题色及高 DPI 逐物理像素选区等仍待补齐。

也可直接用浏览器打开 [HTML 操作说明](docs/Snipaste功能对齐-v0.4.5.html)。

便携版需要保留整个 `FloatShot` 文件夹，包含 `_internal`。不需要额外安装 Python、Qt 或 FFmpeg。目标系统为 Windows 10/11 x64；录屏控制条的可靠排除需要 Windows 10 2004 或更新系统。

第一次启动显示工作台。关闭工作台会收起到系统托盘；双击托盘图标再次打开。退出请使用托盘菜单“退出”。应用启动时不会自动截图、录屏或开启麦克风。

## 当前功能

- **截图：** 框选、窗口和基础 Win32 控件检测、多屏裁切、混合 DPI、放大镜、取色、键盘微调、上次选区、历史回放。
- **标注：** 截图与贴图共用就地工具栏；基础工具、序号、放大镜、圆角/虚线、箭头样式、文字背景与描边、待确认对象移动/克隆/复制/删除、缩放/旋转手柄、撤销重做、共享色板、多笔尖。
- **输出：** 剪贴板、PNG/JPEG/WebP、快速/自动保存、复制为图片文件、自绘边框阴影、配置目标应用后发送图片。
- **贴图：** 图片/文件/网页图片、纯文字/HTML、HEX/RGB 颜色卡片；缩放/透明度/旋转/镜像/灰度/反色/穿透、缩略图/裁剪、分组/Solo/多选、透明背景、关闭恢复、重启恢复布局及完成的标注对象。
- **录屏：** 区域或单显示器整屏，15/30 fps，最高 1080p，鼠标指针、系统声音、麦克风、独立静音、倒计时、暂停/继续和无水印 MP4。
- **管理：** 图片/视频历史、录屏预览、视频文件复制和另存、失效记录提示、缓存上限、保存目录、快捷键冲突提示、可选开机启动。

## 使用步骤

### 截图与标注

1. 按 F1，鼠标拖拽框选；单击可选择检测到的窗口或控件。
2. 松开鼠标后显示底部工具栏。选择箭头、画笔等工具后直接在选区内标注；鼠标悬停工具图标可查看名称。Ctrl+1～7 按从左到右选择标注工具；线条下拉用图形选择直线及三种箭头，方向按钮切换正向、反向和双向；B 选画笔，T 选文字。外层八个控制点调整截图选区；“F10 / 工具栏右键 → 更多工具与操作 → 其他工具”提供选区移动和序号等工具。
3. 折线逐点单击，右键或 Enter 完成；再按 Enter 输出。文字工具在点击处显示内嵌输入框，Ctrl+Enter 完成，Esc 取消当前文字输入。
4. 矩形/椭圆使用十字光标，绘制后自动显示四角、四边和旋转点，共九点。画笔显示当前颜色的圆形笔尖，按下绘制时隐藏、松开恢复。滚轮或 1/2 调整粗细并同步修改最近一个尚未确认的标注，单击子栏最左圆点可展开笔尖；悬停控制点显示缩放/旋转光标，悬停实际绘制边缘显示四方向箭头。点击空白（含选区外）或开始下一笔后确认旧对象，移除控制点且不能重新选择；仍可撤销/重做。直线/箭头仅显示两个端点，拖动一个端点时另一端固定，Shift 约束方向。Alt 召唤局部放大、坐标和颜色。C 复制颜色而不退出截图；Shift 在 HEX / RGB 间切换。
5. Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。Enter / Ctrl+C 复制图片，F3 将当前截图及标注在原截取位置转为置顶贴图，底部工具栏可保存或贴图。取消保存对话框会返回原选区并保留标注。
6. 已有标注时按 Esc 或点击取消会在当前截图选区中心提示确认退出；可勾选“以后不再显示此消息”，也可在设置中重新开启。未标注时直接退出。
7. Ctrl+A 框选当前屏幕，再次按下选全屏；反引号 / ! 切换快照中的鼠标指针。R 重复上次选区；`,` / `.` 回看截图历史。替换已有标注的选区前会提示确认。

### 桌面贴图

1. 截图时选择“贴图”，或复制图片后按 F3。
2. 浅蓝细边框和柔和蓝色阴影位于图像外侧，不改变 F3 截图贴图的位置和显示大小，也不进入普通图片导出。拖动移动，滚轮缩放，Ctrl + 滚轮调整透明度；边缘可拖动调整大小。中键恢复大小和透明度。
3. 1/2 旋转，3/4 镜像，5 灰度；Space 在贴图附近显示同款工具栏，直接标注，再按 Space 完成。
4. 双击或 Esc 关闭贴图，托盘菜单可恢复最近关闭的贴图；Shift+Esc 销毁。
5. Ctrl+Alt+T 切换鼠标下贴图的穿透；鼠标不在贴图上时解除全部穿透。托盘也有解除入口。

### 录屏

1. 工作台选择“区域录屏”或“整屏录制”；区域录屏框选后点击“开始录制”。
2. 在准备窗口选择声音设备、麦克风、帧率、画质及倒计时，电平条可检查声音输入。
3. 录制开始后使用浮动控制条或快捷键暂停、继续和停止；声音按钮可独立静音。
4. 停止后等待声音合成，自动打开视频预览，可播放、打开目录、另存和复制视频文件。

默认声音开关均关闭。开启系统声音时录入所选输出设备；开启麦克风时录入所选麦克风。视频复制的是文件，目标应用需要支持文件粘贴。

| 默认快捷键 | 功能 |
| --- | --- |
| F1 | 截图 |
| F3 | 截图中：当前截图转为置顶贴图；其他状态：从剪贴板贴图 |
| Shift+F3 | 显示/隐藏全部贴图 |
| Ctrl+Alt+T | 鼠标穿透开关 |
| Ctrl+Alt+R | 区域录屏；录制中定位控制条 |
| Ctrl+Alt+P | 暂停/继续录制 |
| Ctrl+Alt+S | 停止录制 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 快速保存图片 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做标注 |
| C / Shift | 复制颜色 / 切换 HEX、RGB |

系统快捷键被其他应用占用时会显示冲突，仍可通过工作台和托盘调用，也可在设置中修改。

## 数据与文件

用户图片和视频默认保存到 Windows 文档目录下的 `FloatShot/截图` 和 `FloatShot/录屏`。可以在设置中修改。

设置、历史缓存、贴图和日志位于 Qt 的用户本地应用数据目录，可在设置中查看。开发测试可通过 `FLOATSHOT_DATA_DIR` 指定隔离目录。

移除历史只删除记录及受管理的缩略图/图片缓存，不删除另存图片或视频。贴图销毁不会删除原图文件。录制异常时临时文件保留在应用数据目录的 `recording` 子目录，错误提示给出具体位置；首版尚无一键异常恢复。

## 当前边界

- 首版面向 Windows；Qt UI 可移植，平台捕获、热键和音频后端暂不承诺跨平台。
- 控件检测使用 Win32 和当前活动窗口 UI Automation，限时/限量遍历，不能覆盖所有自绘/受保护界面，可手动框选。
- W/A/S/D 按物理像素移动光标；选区边界仍为 Qt 逻辑坐标，px/dip 换算有取整差异。
- 录屏选区需位于一个显示器内。窗口跟随录制、多屏合并、GIF、视频裁剪、摄像头、录制中标注未加入；图片 OCR/扫码已支持。
- 录制过程中选区内可见贴图会被录入；暂停会从画面及音频时间轴移除。首版不同时启动截图和录屏。
- 图片导出为位图；贴图工作区保存原图及标注对象；重启恢复的对象视为已确认，可继续添加新标注。裁剪、旋转/镜像和部分显示模式变换会合并原有对象。
- 图片内容默认本地处理，无账号和云服务；视频播放器使用 Qt Multimedia。
- 尚未完成 30 分钟长录制及多种 GPU、DPI、Windows 版本的完整兼容性验收。

## 开发与验证

需要 Python 3.11 x64。推荐使用项目虚拟环境，避免调用系统的 Python 2.7。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m floatshot
```

也可运行 `run.ps1`。首次运行自动创建虚拟环境并安装运行依赖。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/verify_runtime.py
.\.venv\Scripts\python.exe tools/verify_selection.py
```

第二条在 Windows 上验证真实截图、光标与 WASAPI 系统声音，短录制完成后删除桌面录制，仅保留 JSON 测试报告。执行时系统需要有可用的音频输出设备。

第三条在已解锁的 Windows 桌面上验证截图／录屏选区在拖动中和松开后的实际显示，使用合成画面检查选区高亮、边框和遮罩，并保留报告与选区预览。

```powershell
.\build.ps1
```

构建脚本运行测试，生成图标，使用 PyInstaller 打包 Qt、音频依赖和 FFmpeg，最后生成便携 ZIP。`requirements.lock` 记录本次实际使用的运行依赖版本。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `floatshot/app.py` | 主窗口、托盘、功能编排、单实例 |
| `floatshot/capture.py` | 屏幕快照、选区、多 DPI 裁切 |
| `floatshot/editor.py` | 标注模型、渲染、编辑窗口 |
| `floatshot/pins.py` | 贴图窗口、状态、布局恢复 |
| `floatshot/recorder.py` | 录制状态、暂停时钟、WASAPI 音轨、FFmpeg 编码与混音 |
| `floatshot/dialogs.py` | 录屏准备、控制条、预览、设置 |
| `floatshot/native.py` | Windows 热键、显示器、光标、会话与捕获排除 |
| `floatshot/storage.py` | 配置、历史和缓存管理 |
| `tests/` | 交互、数据、标注与实际编码验证 |
