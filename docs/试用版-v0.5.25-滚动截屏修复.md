# picut v0.5.25 · 滚动截屏修复（独立试用版）

本版继续在 `codex/picut-local-translation` 分支发布，没有合入原版。v0.5.21 原版、v0.5.24 及更早试用版的程序、安装包、标签与数据目录保留。

## 修复内容

- 抓屏、持续匹配／拼接、界面预览分别处理。匹配与条带写入不再占用界面线程，预览只读取不可变缩略图快照。旧 Win10 的隐藏控件抓屏路径也把后续匹配交给后台。
- 正常滚动条的滑块位移不同于正文。匹配仅排除视口极窄边缘中符合平直轨道特征的列，不再让滑块否定整幅正文的对齐；原始输出宽度和像素保留。
- 修复窄列代码、大块留白被错误拒绝。共同内容跨越足够多的纵向位置时，可以确认滚动，不要求文字填满画面。仍保留内部小块滚动、无重叠、完全重复内容的拒绝检查。
- 对缩小图上通过的候选位置，增加原始分辨率像素复核，保留小行号、数字等细节的定位作用。变化的细长行号列不再被当作动态图块掩去。
- 明显不匹配的位置提前结束比较。滚动方向与每帧的采集时间一起保存，避免队列积压、反向滚动后套用最新方向。
- 每次滚动截屏结束时记录采集帧率、最大采集间隔、队列合并数量、匹配耗时、排队延迟与失败次数，便于排查实际环境。日志不保存截图像素或文字。
- 无法确认位置时提示“暂未找到可靠重叠”，不再把所有失败都归为跨度过大。

## 使用与回滚

先从托盘退出旧程序，再安装 `picut-0.5.25-translation-trial-setup-x64.exe`；或运行本版便携目录里的 `picut.exe`。工作区的 `run-translation-trial.ps1` 指向本版，`run.ps1` 继续指向原版 v0.5.21。

按 F1 框选实际滚动内容，在工具栏点击“滚动截屏”。可以向上、向下或往返回看，也可使用自动向下滚动。边缘滚动条可包含在选区中。完成前会处理已采集的排队帧，再导出原始像素。

如果某次确实没有留下共同内容，仍无法凭滚轮格数补出缺失像素；程序保留已截内容，回滚少许可继续。未承诺任意页面、任意速度都能成功。

不满意时退出新版，运行 `dist/picut-0.5.24-translation-trial/picut.exe` 即可回到此前试用版。恢复原版则运行 `run.ps1`。本版没有自动安装或替换正在运行的程序。

翻译试用继续提供中英双向本地模型、原位图片翻译、统一发布结果和斜向扫光。本版没有更换 OCR／翻译模型。运行时仍为 C++／Qt，不需要 Python 或服务器。

## 验证与性能范围

在 Windows 11 x64 开发机上测试，不能代替所有 Win10／低配设备验证：

原生回归 118 项通过，4 项桌面数据用例在离屏运行中跳过；这些桌面用例另在 Windows 原生窗口平台运行，6 项检查通过。代码窗口再独立连续运行三轮，每轮 40 步，均无匹配失败、正文像素一致。翻译专项 21 项通过，2 项需要额外指定历史参考截图的用例跳过。

- 用所提供的代码长图作为本地输入，测试多个视口高度、步长、滚动条和小数位置；该截图不进入 Git 或分发包。
- 合成代码含行号、短行、重复括号和大块留白；验证上下延长及往返回看，并比较最终正文的原始像素和高度。
- 独立 Windows 窗口持续滚动 40 步；界面线程每次暂停 90ms，抓屏与拼接仍继续。代码窗口包含真实绘制的滚动条，正文最终逐像素一致。
- Windows 原生输入覆盖滚轮、上下键、翻页、自动滚动和停止；动态聊天覆盖表情播放、刷新、接缝与原始正文保护。

真实桌面测试中采集约 58 帧/秒，代码帧匹配平均约 8.5ms、最大约 12ms，没有排队帧合并或匹配失败。正文和动态聊天匹配耗时更高，具体记录在随包的测试报告中。12ms 的采集间隔是调度目标，不是所有机器实际达到 83 帧/秒的保证；显示器刷新、Windows 调度和画面复杂度都会影响结果。

会话统计在 `%LOCALAPPDATA%\FloatShot\FloatShotNative-TranslationTrial\logs\startup.log` 的 `Scroll session` 记录中；设置独立数据目录时，日志也随之放在该目录下。
