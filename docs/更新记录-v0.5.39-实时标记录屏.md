# picut v0.5.39：实时标记、移动区域和窗口录屏

录屏控制条新增“标记”和“移动录屏区域”。点击“标记”直接展开现有风格的标记工具栏并接管录屏区域内的鼠标输入；关闭工具栏或按 Esc 后恢复操作桌面，已有标记保留。绘制草稿、拖动、改变端点、删除、撤销和清空的变化实时进入后续视频帧，已经录下的画面保留当时状态。所有已完成标记都可以重新点击选中，画笔自由曲线可以整体移动和删除，无缩放控制框。标记工具栏和调整控制点排除在采集之外。

拖动控制条的四向箭头按钮可以在录制中移动采集范围，边框、控制条和标记一起跟随。采集坐标在帧边界读取，编码器不重启，原来的帧尺寸、帧率、声音和视频时间线保持连续。

F1 选区后切换到录屏工具栏，新增“区域”和“窗口”模式按钮。选择窗口模式后点击目标窗口绑定，随后点击开始录制。窗口采集使用 Windows Graphics Capture，不把其他窗口的遮挡画面录进去。目标窗口移动时边框与标记跟随；窗口改变宽高后，将完整内容按宽、高分别缩放到开始时的视频画布，允许压扁或拉伸，不补边、不裁切。窗口最小化时自动暂停，恢复后继续；原先手动暂停的状态不会被自动恢复覆盖。窗口关闭后结束录制并保存。

标记坐标固定在视频画布中，不追踪滚动页面内的对象。窗口缩放时，标记和窗口内容使用相同的映射比例。录制线程只读取不可变的标记绘制缓存，GUI 更新后用共享状态切换缓存；录制线程不会读取 Qt 控件或可变的标记文档。

窗口捕获需要 Windows 10 1903 或更新版本；录制中编辑标记需要捕获排除支持（Windows 10 2004 或更新版本的正常本地桌面会话）。旧系统仍保留区域录屏、外置控制条和预先完成的标记合成。受系统保护、禁止捕获的窗口不保证可录。

程序为 `dist/picut-0.5.39/picut.exe`，安装包为 `dist/picut-0.5.39-setup-x64.exe`，便携包为 `dist/picut-0.5.39-win-x64.zip`。旧版 v0.5.38 的目录、安装包、便携包和源码标签保留，修改前源码另存于 `codex/picut-before-live-recording`。设置和历史目录继续沿用，更新前退出旧版托盘。

本次不调整包体、OCR、翻译、滚动截屏或图标。完整 OCR、翻译回归未重跑；v0.5.37 说明中的翻译超时及取消状态问题未在本次修复。

验证在 Windows 11 的原生桌面完成：录屏编辑与选区相关检查 15 项通过，新增实录检查 5 项通过，解码视频确认了草稿分阶段出现、删除、移动采集位置、窗口移动与变形铺满、遮挡排除、最小化与手动暂停、关闭窗口保存。相关标注与工具栏单元按仓库配置的 offscreen 平台运行，8 项通过。原有录屏检查最后一轮为 16 项通过、2 项因桌面合成器未显示全屏测试画面而跳过，无失败；Win10 版本差异未用独立系统实机验证。
