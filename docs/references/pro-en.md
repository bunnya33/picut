## Snipaste 2 Pro Features

### A. New Features

#### Snip

1. Super-snip

   This feature lets you take a screenshot without using any global hotkeys!

   The setting interface:

   ![super_snip_config](https://user-images.githubusercontent.com/2010459/42830895-5d846142-8a1f-11e8-871c-522b6dec00c3.png)

   So you just need to hold <kbd>Win</kbd> and drag your mouse to take a screenshot:

   ![super_snip](https://user-images.githubusercontent.com/2010459/42724522-632f308e-87a6-11e8-9234-85c5bc9d4219.gif)

2. Hierarchy interface element detection

   Scroll the mouse to select the region of the parent/children element:

   ![snip_hierarchy_detection](https://user-images.githubusercontent.com/2010459/42833290-42552378-8a26-11e8-9b13-483d63237245.gif)

3. Region size input

   The Custom-Snip-Dialog in Snipaste 2.0 allows you to input the position, size and time delay before entering snipping. This feature is included in free version.

   ![region_size_input](https://user-images.githubusercontent.com/2010459/42830997-bdfa8100-8a1f-11e8-8a27-f0fd25892a51.png)

   What Pro version offers you is that you can also input the size of the snipping during snipping:

   ![snip_resize](https://user-images.githubusercontent.com/2010459/42833175-00ec2bde-8a26-11e8-82f2-4b9ce91dad0d.gif)


#### Paste

1. Thumbnail the image by right-drag selection

   ![paster_thumbnail](https://user-images.githubusercontent.com/2010459/42724518-622c3178-87a6-11e8-83e1-cbf695ee6896.gif)

2. Image cropping

   It works like this:

   ![paster_crop](https://user-images.githubusercontent.com/2010459/42834095-a90a6928-8a28-11e8-9460-d5a39f145d35.gif)

3. Image multi-selection

   Hold <kbd>Ctrl</kbd> and click on multiple images windows to have them selcted. You can then move/reset/close/destroy or adjust their opacities all together.

   ![paster_multi_select](https://user-images.githubusercontent.com/2010459/42724516-61ab6b42-87a6-11e8-9ae1-e5d4572bc890.gif)

4. Paste or drag image from webpage

   You can either:
   * Copy image from the context menu, then paste it using Snipaste's hotkey (default <kbd>F3</kbd>)
   * Drag the image onto an existing image window
   This feature requires Internet connection. Support Firefox/Chrome/Edge.

   ![network_image](https://user-images.githubusercontent.com/2010459/42724512-605faeba-87a6-11e8-97ee-95f6746f0135.gif)

5. Solo mode

   Solo mode allows you to show some of the image windows and hide others, temporarily. You can combine with the multi-selection operation to solo multiple images:

   ![solo](https://user-images.githubusercontent.com/2010459/42832998-8fc631a2-8a25-11e8-8199-9016ba5fff5a.gif)

6. Background mode (Transparent, pseudo-transparent, dark chessboard, light chessboard)

   You can specify the default background mode in the Preferences Dialog:

   ![backgound_mode](https://user-images.githubusercontent.com/2010459/42831398-cea0b366-8a20-11e8-8455-d8623a220357.png)

   Or change the background mode on a specific image window：

   ![individuate_background_mode](https://user-images.githubusercontent.com/2010459/42831476-063dd6d2-8a21-11e8-82e2-ffb807f20bdc.png)

   Four background modes:
   * Transparent: the transparent parts of the image would not be painted and therefore such regions would be unclickable
   * Pseudo-transparent: the transparent part is still displayed as transparent, but you can click on the whole image
   * Dark chessboard: paint the transparent parts with a dark chessboard
   * Light chessboard: paint the transparent parts with a light chessboard

7. Topmostness toggling

   Now you can turn off the topmostness of an image windows:

   ![snipaste_2018-07-04_01-14-36](https://user-images.githubusercontent.com/2010459/42831509-22a70c3a-8a21-11e8-9d01-d7d3e0e83f6b.png)


8. Grayscale conversion

   As we know, pressing <kbd>1</kbd>、<kbd>2</kbd>、<kbd>3</kbd>、<kbd>4</kbd> on an image window can rotate or flip the image. Now press <kbd>5</kbd> to convert the image into grayscale (and press <kbd>5</kbd> again to change it back).

9. Edit the color card

   If the image is a color card, you can change its color value.

   ![color_card_edit](https://user-images.githubusercontent.com/2010459/42831603-58310d24-8a21-11e8-8ff3-6cad4b175613.png)

10. Image group management

   No you can add/remove/rename/sort the image groups in one place:

   ![image_group_management](https://user-images.githubusercontent.com/2010459/42831655-7bd120c0-8a21-11e8-9c67-4169a9c54805.png)

#### Annotate

1. Re-edit the annotations

   You are allowed to re-edit the annotations of the selected type on the paint bar. You can also press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> to copy the selected annotation and then press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd> to make a clone. Or you can simply hold <kbd>Ctrl</kbd> and drag the selected annotation to duplicate it. Press <kbd>Del</kbd> to delete it.

   ![reedit](https://user-images.githubusercontent.com/2010459/42724511-601c23d4-87a6-11e8-8e97-564e8fcd9ddf.gif)


2. Draggable and wheelable color buttons

   Drag and drop the color buttons to exchange their positions. Scroll your mouse on the big color button to change its opacity.

   ![color_buttons](https://user-images.githubusercontent.com/2010459/42724515-616b3df6-87a6-11e8-9727-68d76440d7e7.gif)

3. Individually remember the colors of different annotation types

   ![separate_colors](https://user-images.githubusercontent.com/2010459/42831751-c3814800-8a21-11e8-9984-cc606cd63614.png)


#### Others

1. Copy the image file as well as the image content

   ![cppy_as_file](https://user-images.githubusercontent.com/2010459/42831705-9f8ccf32-8a21-11e8-802a-e7bbe145756d.png)

   With this option checked, every time you copy an image within Snipaste, the image will be able to be pasted (<kbd>Ctrl</kbd> + <kbd>V</kbd>) into a file explorer and saves as a file!

   ![ctrl_v](https://user-images.githubusercontent.com/2010459/42724514-612633be-87a6-11e8-929a-163b0a4de651.gif)

2. Hot corners

   When you move the mouse to the screen corners, Snipaste can automatically perform some actions:

   ![hot_corner](https://user-images.githubusercontent.com/2010459/42831807-e9898ed6-8a21-11e8-9171-48f54be73224.png)

   According to the settings, when the mouse is at the top left corner or top right corner, Snipaste will automatically hide/show all the image windows. This is a very handy feature which I use it tens of times every day!

### B. Higher freedom of customization

1. Create a hotkey for any function of Snipaste

   The free version only allows to bind global hotkeys for a few functions. In Pro version, you can create a number of them!

   ![create_new_action](https://user-images.githubusercontent.com/2010459/42831830-fa9e8776-8a21-11e8-81ee-76acac9158c1.png)

   A few common actions have been set up for you:

   ![custom_command](https://user-images.githubusercontent.com/2010459/42831880-1f17f830-8a22-11e8-9585-243515f5d377.png)

   where `command` is from [Command line options](https://github.com/Snipaste/feedback/wiki/Command-Line-Options). You can also click on the bottom left icon to show the documentation. You can input any command you like, e.g. **Take a screenshot of the same region of last capture and copy it** has a simple command `snip --last -o clipboard`.

   Additionally, you can tell Snipaste which programs to ignore the hotkey when they are active. For example, in the above setting, it means if the active windows belongs to the program whose executable name is `a.exe` or whose location path contains the the directory `games`, the hotkey will not be effective. You can make use of this feature to avoid activating Snipaste when you are enjoying a game :)

2. Full control of the appearance of the magnifier

   ![full_control_magnifier](https://user-images.githubusercontent.com/2010459/42831917-3e6e290c-8a22-11e8-9f20-2f58954aefab.png)

3. Customize the mouse actions of tray icon

   The actions when you left-click, middle-click or right-click the tray icon of Snipaste are all customizable:

   ![tray_actions](https://user-images.githubusercontent.com/2010459/42831964-6401be18-8a22-11e8-93a0-506d0d0e4245.png)

4. More number of pen thicknesses

   ![more_pen_sizes](https://user-images.githubusercontent.com/2010459/42832019-81049058-8a22-11e8-9d54-ab55616a602f.png)

   Display more than one pen thickness. Each of them can change its thickness by mouse scroll.

   ![three_pens](https://user-images.githubusercontent.com/2010459/42234208-6486533c-7f26-11e8-946f-e6b5d1460de4.png)

5. Customizable and sharable palette

   ![palette](https://user-images.githubusercontent.com/2010459/42832088-b37facf2-8a22-11e8-97df-900c4fb083c7.png)

   Welcome to share the palette with your friends!

6. Save ALL snip records

   ![record_all_snips](https://user-images.githubusercontent.com/2010459/42832109-c81c8d1a-8a22-11e8-93f0-2a0811e8009c.png)

   The free version only records successful captures. With this option checked, even aborted captures will be recorded, getting rid of the embarrassment when you mistakenly press <kbd>Esc</kbd> and lose your screenshot.
