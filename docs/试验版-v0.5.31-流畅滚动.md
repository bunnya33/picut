# picut v0.5.31：修复不等距回滚后持续匹配失败

本版继续在 `codex/scroll-performance-trial` 分支开发，沿用 v0.5.29、v0.5.30 的试验配置和安装身份，保留旧版程序、安装包及 Git 标签。

## 问题和结果

典型操作是：先向上滚动 100px 并截取，再向下回滚 100px；下一次向上滚动 120px，之后每次滚动 100px。后续停靠位置始终与首轮相差 20px。软件应根据当前画面与已截长图的重叠内容定位，不能要求再次回到首轮顶边。

在本机聊天图片的不等距回放中，v0.5.30 存在这样的失败：正确位置的大范围重叠像素完全一致，但另一处重复表情也通过了允许局部重绘的校验。两处均缺乏足够唯一的行特征时，程序直接拒绝。随后继续丢失可靠跟踪的标记，使之后的恢复更困难。程序没有按固定滚轮距离拼图，问题出在冲突候选的判断和可靠参照的延续。

本版在完整重叠核验之后增加一项有条件的判断：

- 上一幅参照画面必须已经建立可靠位置；被拒绝的画面不替换这个参照。
- 当前候选必须得到光流位移的独立支持，并通过整数位置的逐像素完全一致检查。
- 已确认内容必须至少覆盖当前画面的三分之二，与参照的移动不超过画面高度的三分之一。
- 满足上述条件时，一个允许局部差异的相似历史位置不再单独否决这个完全匹配的位置；恢复后保留可靠跟踪状态。
- 两处均为完全一致、只有短边缘重叠、没有建立可靠位置等情况，仍保留原有歧义保护。不会按滚轮刻度猜测缺失内容。

候选位置仍由快速跟踪和历史索引提出，再核对该位置整个重叠部分。没有逐帧从头扫描整张长图，也没有用空白背景占比作为唯一匹配率。历史回访不增加成图，真正超过已截边界才补入新内容。

## 验证

本机 Windows 11、Ryzen 5 9500F、32GB RAM：

- 新增段落、代码、聊天以及用户聊天截图的不等距向上滚动与反向回滚测试；整数位置和每次导出的原图均逐像素核验。
- 将上述 `100 → 回滚100 → 120 → 每次100` 顺序单独加入代码和真实聊天回放；测试过程不再返回首轮的 100px 停靠位置。
- 同时覆盖中途一帧被遮挡并拒绝后，从相差 20px 的新位置恢复；被拒绝帧不得改变已确认图片。
- 增加 120.25px 等分数位置的向上滚动和往返过程，允许至多一像素的输出坐标取整差异。
- 长截图引擎离线回归为 **46 通过、0 失败**，两个真实桌面采集用例另行通过。保留重复内容拒绝、返回起点不误补顶部、动画、悬停、真正向上补图等回归。
- 基础功能回归 **120 通过、0 失败**；五个桌面业务场景另行通过，覆盖实际采集、预览、鼠标键盘输入和异步导出。受控静态桌面的最终成图与参考逐像素一致。正常段落滚动场景的“源窗口请求重绘到预览 Paint 开始”延迟 P95 为 62.780ms，P99 为 71.897ms；不含显示器实际呈现。
- 1000×800 选区、77 次更新回放得到 30800px 高度，成图与静态参考逐像素一致；本轮离线处理 P95 为 12.350ms，P99 为 13.063ms，测试进程工作集增量约 26.65MiB。离线指标不包含桌面采集、预览呈现或最终大图导出的峰值。

本轮记录位于 `.test-artifacts/native-v0.5.31-*`。用户参考图片保存在本机隔离测试目录中，不进入 Git 或安装包。上述为固定回放结果，不能视为任意页面的成功率。

## 安装和回退

- 安装包：`dist/picut-0.5.31-scroll-trial-setup-x64.exe`。
- 便携包：`dist/picut-0.5.31-scroll-trial-win-x64.zip`。
- 工作区入口：`run-scroll-performance-trial.ps1`，默认静默进入托盘。
- 更新前先从托盘退出正在运行的试验版。安装器不主动结束旧进程。
- 沿用 `%LOCALAPPDATA%/Programs/picut-scroll-performance-trial` 和 `%LOCALAPPDATA%/FloatShot/FloatShotNative-ScrollPerformanceTrial`，保留设置、历史与贴图。
- 回退 v0.5.30：退出本版，启动 `dist/picut-0.5.30-scroll-trial/picut.exe`，或使用已保留的 v0.5.30 安装包。
- Astra v0.5.27 的入口仍为 `run-scroll-trial.ps1`，正式版入口仍为 `run.ps1`，两者数据目录与本版独立。

安全上限与平台范围沿用 [v0.5.29 说明](试验版-v0.5.29-流畅滚动.md)，包括 6400 万像素、100000px 高度等限制。本轮未在 Windows 10 实机验证；大幅跳过全部重叠内容或完全相同的重复画面仍可能无法定位。
