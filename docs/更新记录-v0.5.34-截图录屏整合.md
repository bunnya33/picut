# picut v0.5.34：统一截图与录屏入口

已验收的 v0.5.33 长截图实现合入主分支，正式安装包使用普通 picut 安装身份。本版新增 F1 截图选区直接切换录屏，以及携带截图标注的实时录制。

## 操作

1. 按 F1 选择截图区域，可以先画箭头、矩形、画笔、文字、序号或高亮。
2. 点击截图工具栏中的摄像机按钮，工具栏切换为返回、设置和开始录制，区域及标记保留。设置主动打开并在设备上记忆。
3. 开始前按 Esc 或点击返回，回到截图模式继续编辑；取消倒计时也会恢复选区与标记。
4. 点击开始或按 Enter，按保存的设置录制。Ctrl+Alt+P 暂停 / 继续，Ctrl+Alt+S 结束。托盘仍保留全屏录屏入口及原有设置行为。

独立的区域录屏快捷键已移除，旧设置中的 Shift+F1、F2 或自定义录屏绑定不会继续注册。设置面板移除这一独立项，截图选区与其他快捷键仍可通过直接按键修改。

录屏选择工具栏及录制控制条使用与截图一致的浅灰背景、蓝色细边框、32px 按钮和 16px 图标；返回、设置、开始、暂停、继续、停止使用统一的线条图标。

## 标注录屏

已确认的画笔、箭头、矩形、椭圆、文字、序号和高亮会合成到每一帧实时画面中，普通图形及文字预先绘制并复用。背景继续更新；马赛克、模糊和放大效果按原有标注顺序处理当前画面，橡皮擦恢复当前帧对应位置。

标记固定在选区坐标中，不追踪滚动内容、窗口或页面对象。正式开始后不能继续编辑标记；需要修改时，在开始前返回截图调整。截图中的选择控制点、工具栏、放大镜和退出提示不会成为视频标注。

支持捕获排除的桌面会话中，标记以鼠标穿透窗口显示，方便对照；这个窗口从原始捕获中排除，视频另行合成一次，半透明高亮不会叠加两次。较老系统无法排除此窗口时不显示该预览层，标记仍正常合成到视频，控制条沿用已有兼容处理。实测平台与验证范围如下，不代表已在 Windows 10 实机完成验证。

## 安装与回退

- 正式安装包：`dist/picut-0.5.34-setup-x64.exe`。
- 免安装包：`dist/picut-0.5.34-win-x64.zip`，解压后保留完整目录。
- 启动入口：`run.ps1` 或 `dist/picut-0.5.34/picut.exe`，默认静默进入托盘。
- 安装使用 `%LOCALAPPDATA%/Programs/picut` 和原正式版 AppId；更新前先退出旧托盘，安装器不主动结束进程。
- 沿用已验收长截图的数据目录 `%LOCALAPPDATA%/FloatShot/FloatShotNative-ScrollPerformanceTrial`，保留当前设置、历史和贴图。v0.5.26 的旧正式配置目录继续保留，不自动合并。
- v0.5.33 的安装包、程序目录、源码标签和 `run-scroll-performance-trial.ps1` 保留，退出本版后可直接回退。
- `backup-main-before-v0.5.34-20261024` 保存合并前主分支；历史正式版和 Astra 版本继续保留，见 [版本回滚](版本回滚.md)。

## 验证

开发测试使用隔离数据目录。覆盖 F1 工具栏切换、Esc / 返回、标记与选区保留、倒计时取消、旧热键解除、设置记忆、实时画面合成及标注绘制顺序。实际编码的视频经过解码检查，确认标记写入成片、半透明标记仅叠加一次、录屏边框和控制条被排除；同时检查强制兼容模式。

最终测试记录位于 `.test-artifacts/native-v0.5.34-*`。测试主机为 Windows 11、Ryzen 5 9500F、32GB RAM。

- 原生回归 124 项通过；离屏环境跳过的 5 项桌面用例已在 Windows 桌面补测，连同模式切换及倒计时取消共 9 项通过。另有分数缩放造成 1px 尺寸差异的模拟验证。
- 长截图 V2 回归 62 项通过，2 项桌面用例另行运行通过；包含用户原图重放及不等距往返、加载卡片重绘样本。
- 实际桌面录屏 15 项通过，无跳过，覆盖区域、全屏、第二屏、兼容模式和标记仅合成一次的解码验证。
- 本地 OCR 13 项通过；翻译 21 项通过，2 项需要指定额外参考图片的可选用例未运行。F3 原位贴图及异步持久化检查通过。

1000×800 静态代码样本连续拼到 30,800px，77 次定位全部成功，离线匹配 P95 为 11.67ms、P99 为 12.72ms；未达到 8ms 的内部 P95 目标。该指标不含采集和显示时间。独立 Windows 桌面变化测试的预览 P95 为 47.02ms，10 次变化均被跟踪；这些测试结果不代表任意页面都能无损拼接。
