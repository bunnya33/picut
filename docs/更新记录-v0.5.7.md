# 浮光 v0.5.7：工具栏实时跟随和参考图样式

截图选区和录屏选区在移动、调整大小时，工具栏随每次鼠标移动同步定位，不再等到松开鼠标才跳到新位置。鼠标抬起前即使没有收到最后一帧移动事件，也会使用松开的位置完成定位。

截图与录屏选区使用相同的位置计算：工具栏右侧对齐选区，屏幕底部空间不足时放在选区上方，并限制在当前屏幕和截图窗口内。方向键微调录屏选区时也会同步移动工具栏。正在录制的区域保持固定，计时、暂停、结束和捕获排除功能保持原有行为。

截图及贴图编辑的主工具栏按照提供的参考图调整：浅灰底色 `#f2f2f2`、1 像素蓝色边框 `#2080f0`、直角背景、32×32 按钮、16×16 图标、两处分隔线。图标轮廓来自用户提供的参考图片，去除背景后嵌入程序，不依赖临时图片路径；支持高 DPI 和选中、禁用状态。没有可撤销或重做的内容时，对应按钮显示灰色并禁用。工具参数行与主工具栏靠右对齐。

保留原有工具顺序、快捷键、颜色及样式记忆，以及 v0.5.6 的普通画笔和马克笔规则。OCR 继续使用 PP-OCRv6 Small。

回归检查覆盖截图和录屏选区在松开鼠标前的连续移动、连续缩放、最后松开位置、方向键微调和底部避让。工具栏渲染与参考图逐像素比较，验证尺寸、边框、底色、图标和间距。预览保存在发布目录的 `annotation-previews/`。

本轮原生 34 项、OCR 11 项、录屏 10 项检查全部通过，无跳过。录屏检查包含区域、全屏和第二屏的成片捕获排除。仅使用 Windows 系统 PATH 的便携环境中，34 项原生回归及发布程序的 F3 合成检查也通过；五张贴图保持原位置并成功保存。

先从旧版托盘菜单退出旧版，再运行 `dist/FloatShot-Native-0.5.7/FloatShotNative.exe`，或使用根目录 `run.ps1`。请保留整个程序目录。
