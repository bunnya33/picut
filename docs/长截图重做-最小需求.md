# 长截图重做：最小需求

## 目标

为 picut 重新设计一套可靠、流畅的长截图能力。优先把基础体验做好，允许从头设计，不要求沿用现有实现。

## 基础功能

- 用户框选屏幕区域后，从截图工具栏进入长截图，手动纵向滚动内容。
- 将滚动经过的内容拼成一张连续长图。正常滚动、快速滚动和往返查看时，尽量不漏内容、不重复、不产生错位或覆盖。
- 过程中实时显示长图预览；图片变长后，预览自动适应屏幕。
- 用户可以结束并复制、保存结果，也可以取消。结果能接入现有截图、标注与贴图流程。
- 无法继续拼接时给出清楚反馈，并保留已经正确捕获的内容。

## 范围与优先级

第一版优先覆盖网页、文档、代码和聊天记录中的静态内容，先做好手动纵向滚动。固定侧栏、局部动画等真实页面情况需要考虑，但可以分阶段完善；自动滚动等扩展能力可以后续再做。

运行在现有 Windows 10 及以上的 C++ / Qt 应用中，使用本地处理。兼容范围沿用项目现状。

## 给方案设计者的空间

请自主选择采集、定位、拼接和交互策略，不预设帧率、算法、线程模型或判断阈值，也不要求保留旧长截图代码。既有缺陷只说明可靠性不足，不应把旧补丁逐条变成新方案的约束。

希望得到一份独立的新方案，讲清整体思路、首版取舍，以及如何用小规模原型验证它是否可靠。现阶段只做方案，不开始修改程序。
