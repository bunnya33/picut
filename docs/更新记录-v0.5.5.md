# 浮光 v0.5.5：F3 贴图响应修复

本版保留 v0.5.4 的 PP-OCRv6 Small 离线 OCR，修复截图后 F3 贴图时界面等待的问题。录屏功能、截图原位置贴图、标注效果和通知设置保持原有行为。

## 原因与修改

旧流程先显示贴图，再在同一次界面线程调用中压缩截图 PNG、保存历史，并重读整个工作台历史列表。截图关闭时会再次刷新列表；即使工作台隐藏，也会读取全部历史图片。贴图显示后的 400 ms 保存定时器还会同步重写所有贴图 PNG，拖动、缩放和透明度变化也触发图片压缩。

本版 F3 先创建并绘制贴图；图片保存使用单个按需启动的后台工作线程，空闲后回收。PNG 使用原子替换写入。工作台隐藏时只记录历史需要刷新，显示后再刷新；最多缓存 128 张 96×60 缩略图。保存贴图只编码新图片或内容发生变化的图片，位置、缩放、透明度等变化只写布局。

保存队列会依次执行图片写入和销毁，防止待保存贴图在销毁后重新生成缓存；正常退出会排空保存队列。后台保存失败时保留屏幕上的贴图并报告错误，失败图片不会登记为可恢复贴图或历史记录。

## 合成截图对照

同一台电脑，2560×1440 合成桌面、1800×1100 选区、90 条历史记录，连续 5 次走截图的 F3 按键处理。没有读取用户屏幕、修改剪贴板或写入用户历史。

| 测量项 | v0.5.4 旧流程 | v0.5.5 |
| --- | ---: | ---: |
| F3 处理平均耗时 | 6303.5 ms | 25.2 ms |
| 贴图首次绘制平均耗时 | 6305.7 ms | 28.6 ms |
| 工作台隐藏时每次读取历史图片 | 182～190 张 | 0 张 |
| 5 张贴图持久化的界面线程调用 | 546.65 ms | 0.07 ms |
| 重新打开历史列表 | 全部图片 | 仅新增的 5 张 |

新版基准特意阻塞图片写盘队列，待贴图首次绘制后才解除阻塞，用于确认首次显示不依赖磁盘写入。持久化数字表示界面线程提交任务的时间，PNG 完整保存仍在后台完成；它不表示磁盘保存时间缩短到 0.07 ms。五张贴图已排空队列后检查持久化成功，原位置均保持正确。实际截图复杂度、磁盘速度和设备差异会影响延迟。

数据：`.test-artifacts/native-v0.5.5-pin-comparison.json`；新版对照来自最终发布包，PATH 仅包含 Windows 系统目录。

## 回归验证

检查覆盖后台历史保存与失败、移动/透明度/缩放不重写图片、标注变更保存、待写贴图销毁不复活、正常退出排空队列、恢复后原位置与像素一致，以及原有保存取消、截图和录屏流程。完整构建同时运行原生、OCR 和录屏测试。另检查连续贴图自动保存文件不会重名，以及历史索引写入失败时不会留下未登记缓存。

验证结果：原生 24 项通过，离线 OCR 11 项通过，便携环境 12 项通过，合成 F3 与五张贴图退出持久化通过。录屏界面 7 项通过，3 项真实捕获排除检查因当前桌面合成器不可见而跳过；本轮未验证这三项成片排除。

## 使用

退出旧版托盘程序后运行 `dist/FloatShot-Native-0.5.5/FloatShotNative.exe`，或用根目录 `run.ps1`。请保留整个发布目录。用户设置、历史与贴图继续使用原本地数据目录。
