# picut v0.5.48：标注旋转与原画录屏

- 新建标注时角度从 0° 开始；已画好并旋转的标注保留原有角度，调整其粗细不清除旋转。颜色、粗细等偏好继续记忆。
- 马赛克与模糊的区域模式按参考视频显示：绘制时实时生效并显示细实线轮廓；松开后显示深灰虚线边界、八个方形缩放点和顶部蓝色旋转点。
- 调整、移动、旋转过程中收起控制点，保留细实线轮廓，松开后恢复。顶部旋转点使用旋转箭头光标；缩放光标随框的角度变化。顶部控制点超出截图选区时仍可拖动。
- 区域控制点沿标注自身方向排列，修复旋转后的马赛克/模糊框按外接矩形调整造成几何偏移的问题。
- 录屏设置支持 15、30、60fps，默认仍为 30fps，保存后下次继续使用。
- 增加“原画 · 保留原始分辨率”：移除常规档的 1080p 缩小，减少压缩。仍为兼容常见播放器的压缩 MP4，不承诺逐像素无损。编码需要偶数尺寸时只在最右或最下补一像素，不缩放原始画面。
- 原画、60fps 会增加文件体积和性能开销，实际流畅度取决于录制尺寸与电脑性能。其他清晰度档位保持原有分辨率与压缩策略。

本次仅验证标注几何、旋转、新标注角度、录屏设置保存以及合成画面的视频编码，不运行 OCR、翻译、长截图和录屏桌面交互的完整回归。

验证结果：原生程序与测试目标编译通过，相关定向检查共 18 项通过、0 项失败。覆盖九种标注区域的旋转与新标注角度、选区外旋转手柄、15/30/60fps 设置保存和取消，以及 1922×1082 原分辨率与 321×181 奇数尺寸补齐的合成画面编码；FFmpeg 解码确认输出为 60fps。已查看马赛克/模糊框的旋转过程与松开后控制点预览。未以本次合成编码检查推断用户机器的实际高分辨率 60fps 性能。

安装包 `dist/picut-0.5.48-setup-x64.exe`，免安装包 `dist/picut-0.5.48-win-x64.zip`。更新前退出旧版；v0.5.47 程序、安装包与源码标签保留。
