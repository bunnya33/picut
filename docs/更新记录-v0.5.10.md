# 浮光 v0.5.10：单击返回画笔和空心描边

修正参数栏最左侧粗细数字/圆点按钮只打开滑块、无法直接选回画笔的问题：

- 马克笔、马赛克、模糊、橡皮擦：左键点击直接选择画笔模式，区域按钮取消选中，左侧按钮显示蓝色。马克笔的画笔仍为起点与终点之间的直线。
- 矩形、椭圆：左键点击直接选择空心描边，填充开关取消选中。
- 已选中的画笔/描边模式再次点击时保持原状，不打开弹窗，也不增加撤销记录。旁边的填充和区域按钮仍可一键切换回对应模式。
- 粗细滑块改为右键该按钮打开，不改变当前填充/区域模式。滚轮和1/2键继续调整粗细。没有上述模式切换的画笔、箭头、序号工具保留原有左键调尺寸操作。

截图与贴图标注共用此规则。切换会同步更新最近一个未确认的标注，保留位置、粗细与颜色，并记忆所选模式。按钮提示已说明单击和右键的作用。

原生回归 61 项、离线 OCR 11 项全部通过。新增交互覆盖截图/贴图中的矩形、椭圆、马克笔、马赛克、模糊及橡皮擦模式切换，以及右键调粗细时保留当前模式；仅保留 Windows 系统 PATH 的便携运行环境中，这些检查同样通过（含初始化/清理共22项）。F3 原位置贴图和后台保存检查通过。录屏控制检查7项通过，3项真实成片捕获排除检查因当前桌面未向GDI显示测试画面而跳过，本轮未重新验证实际成片排除。交互检查使用临时配置与合成底图，未修改用户配置和历史图片。
