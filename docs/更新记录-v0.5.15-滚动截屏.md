# picut v0.5.15 · 滚动截屏

## 使用方式

1. F1 框选实际需要滚动的内容，点击底部工具栏中“文字识别”右侧的“滚动截屏”图标。
2. 在原页面中滚动鼠标，或点击 ▶ 自动向下滚动；再次点击暂停。区域内可操作原窗口。
3. 右侧实时展示完整长图。优先使用右侧空间，其次左侧；空间不足时靠当前屏幕边缘显示。图片高度超过可用高度后，宽高同步缩小，始终展示完整结果。
4. 点击绿色勾或 Enter 完成并复制；保存按钮另存长图；画笔按钮完成后打开可标注的贴图；Esc 或叉号返回原截图框选状态。

预览缩放不改变导出的像素尺寸。只有纵向向下滚动追加新内容；向上回看已经采集的内容不会重复添加，回到新内容后继续拼接。

## 拼接与边界

前后画面稳定后才进行像素重叠匹配，使用实际滚动位移拼接。滚动内容在上方新帧与下方旧帧的边缘都需要符合相同滚动关系。判断不依赖变化面积的占比，也不要求左右两侧一起滚动：左侧固定栏、右侧滚动内容贯穿上下边缘时，允许截长图。匹配忽略静止列，按滚动部分计算位移，但仍按整幅宽度追加，因此固定侧栏会分段重复，不会自动裁掉。

如果滚动只发生在四周被静止内容包围的内部小窗口，或滚动列的上下边缘仍隔着固定标题栏/底栏，则不直接拼接，请重新框选实际滚动内容。编辑器的小范围光标闪烁不作为滚动。

匹配不可靠、跳动过大、页面切换或局部滚动时，停止自动滚动、显示原因并保留已有结果；可以返回已知位置继续或保存。自动滚动连续三次没有推进时停止，可继续手动操作。自动模式仅在鼠标仍处于原窗口选区时注入滚轮，移开即暂停。

原始像素按新增条带写入会话临时目录，内存中保留匹配帧与缩略图，取消或完成关闭后清理。结束时才合成原尺寸图片。上限为 6400 万像素、10 万像素高度或 1200 个条带，以先达到者为准；上限前的结果可保存。

界面控件位于选区外时不进入图片；Windows 支持时启用捕获排除。旧版 Windows 10 不支持捕获排除且控件必须放在选区内时，采样前短暂隐藏重叠控件、刷新合成后恢复。

## 验证与限制

测试覆盖精确接缝、反向回看、内部滚动拒绝、小区域正确框选、预览尺寸、工具栏入口和取消返回。真实 Windows 桌面测试覆盖手动滚动、自动滚轮穿透和输出原图像素一致性。

2026-10-16 本轮原生回归 83 项通过，1 项真实桌面用例在离屏环境跳过；Windows 下滚动专项 6 项通过，1 项因系统锁屏跳过。最新的完整“F1 框选 → 点击滚动截屏 → 实际滚动”用例仍需解锁后复测，锁屏跳过不视为验证通过。报告分别为 `.test-artifacts/native-v0.5.15-tests.txt` 和 `.test-artifacts/native-v0.5.15-scroll-windows-tests.txt`。

首版适用于能稳定绘制的纵向内容。视频、持续动画、完全相同的重复行、滚动跨度超过可匹配范围，以及很慢的动态加载可能暂停拼接。不同应用、DPI 和旧版 Windows 10 仍需实际使用验证。
