# v0.3.0 更新与验证

交付日期：2026-10-07。截图、标注和贴图以 Snipaste 操作为目标，录屏模块沿用原实现。当前功能与差异以 [Snipaste 功能对齐 v0.3](Snipaste功能对齐-v0.3.md) 为准。

## 本版变化

- 截图：Space 移动正在框选的区域、中键贴图、Shift 快速保存、Alt 放大镜、工具独立参数、尺寸/比例/圆角/白板/F5 刷新、活动窗口和区域命令、光标图案、延时、未完成截图历史、UI Automation 元素检测和滚轮层级矩形选择。
- 标注：序号、放大镜、圆角、虚线/点线、箭头方向及头部、文字背景/描边、对象选择/移动/缩放/旋转/克隆/复制/粘贴/删除、文字四角和旋转手柄、多笔尖、色板排序与导入导出。
- 贴图：Space 就地工具栏、可重启恢复的标注对象、Ctrl+W 和 F3 恢复、中键重置、Alt 取色、区域缩略图/裁剪、分组管理、多选移动/透明度、Solo、灰度/反色、置顶开关、透明背景输入区域、RGB/HTML/文件路径和网页图片。
- 识别：Windows OCR 和 ZXing-C++ 本地条码/二维码识别，结果可编辑与复制。
- 定制：命令行调用、命令快捷键和忽略程序、托盘鼠标动作、屏幕触发角、可选 Win+拖拽截图、配置目标应用发送图片。
- 录屏：`floatshot/recorder.py` 未修改；录屏选区保留旧行为，截图新增操作不会启动标注或改变录制输出流程。
