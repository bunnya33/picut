# picut v0.5.19 · 动态表情滚动截屏

用户反馈聊天记录中的动态表情既会在页面静止时引起对齐失败，也会在滚动时干扰拼接。本次用多个独立、大幅变化的模拟表情复现了这两种情况：v0.5.18 会返回无法匹配。

## 匹配与接缝

- 对齐后把局部变化分成独立区域，不再要求所有变化都集中在一个小矩形内。页面静止时，稳定内容确认没有滚动后只更新匹配参考，不增加高度，也不改动已经截好的图片。
- 滚动时先由稳定的局部特征提出位移，再对变化区域之外的文字、气泡和图像边缘确认。动画忽略区域的数量、面积和形状有上限，并要求剩余稳定特征足够分散。
- 保留单行文字差异参与检查，避免将不同聊天消息中的数字也当成动画忽略。收紧对齐误差，保留重复内容、无重叠跳转、内部小范围滚动和固定头尾的拒绝检查。
- 检测到的动画跨过拼接处时，移动接缝并用同一张原始抓帧中的重叠像素覆盖该部分，减少表情上下两半来自不同动画帧的问题。上下补图都适用。最终长图仍为静态图片，不包含 GIF 动画。
- 原始像素继续存入临时条带，重叠替换时回收不再使用的条带或像素，不在内存中反复创建完整长图。不增加运行依赖。

## 验证

新增测试覆盖静止时多个表情持续变化、滚动中变化、上下往返、接缝跨表情、8 种无重叠聊天跳转和完整截屏会话。导出的静态文字、气泡与背景逐像素比对；完整表情必须来自实际观察到的某一张完整抓帧，不能混用两帧。

Windows 实桌面测试使用合成聊天窗口持续重绘表情，并发送真实滚轮输入和开启自动滚动，检查静止不增长、手动与自动截取、到达底部后自动停止。这里只采集测试窗口，不使用个人聊天记录，也不写系统剪贴板。

完整回归 106 项通过、0 失败，3 项实桌面用例在离屏平台跳过；随后 Windows 桌面验证 5 项通过（含初始化、清理）、0 失败、0 跳过。首次键盘用例因 Windows 拒绝后台进程获取焦点而失败，改为实际点击无遮挡的测试窗口后重测通过，没有修改产品的焦点行为。普通 1280×900 合成图连续 40 步，匹配、预览与条带写入中位约 8.3ms、P95 约 10.4ms；不含抓屏与导出，不代表复杂动画页面的耗时。

回归结果与发布校验见 `.test-artifacts/native-v0.5.19-tests.txt`、`native-v0.5.19-scroll-windows-tests.txt` 和 `native-v0.5.19-release-report.json`。

这些验证不等同于对所有聊天软件的保证。动画占据大部分视口、缺少分散的稳定内容、表情大到无法在任何一帧中完整出现、快速跳过全部重叠内容时仍可能无法匹配或完整保留表情。无法确认位移时保留已截结果，不推算未采集像素。

## 使用与回滚

安装包为 `dist/picut-0.5.19-setup-x64.exe`，便携包为 `dist/picut-0.5.19-win-x64.zip`。先退出旧版托盘后再启动新版，配置和历史路径沿用原设置。

v0.5.18 的程序和安装包继续保留，源码标签 `v0.5.18-scroll-matching`。本版标签为 `v0.5.19-animated-scroll`。
