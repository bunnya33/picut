# picut v0.5.32：接续边界处后来绘制的内容

本版修复“长图到‘开始做吧’附近停止，继续向上滚动仍无法接入上一条回复”的实际图片样本。继续使用 `codex/scroll-performance-trial` 分支和现有流畅性试验版的数据目录；v0.5.31 及更早版本保留。

## 本次发现

两张参考图按未变化的“开始做吧”气泡对齐后，气泡像素完全一致，但其上方在已截长图中是空白，在后来的画面中显示出了文件卡片。这里发生了重叠区域的内容变化，现有完整重叠检查因此拒绝候选位置。仅凭两张图片不能确定页面内部是延迟绘制、加载还是其他布局更新。

修复前已用这两张图复现：历史索引找到了正确位置，但普通重叠核验拒绝。第二张图为单独框选的 840×579px 图片，测试将它横向对齐 8px 后与 817px 宽的长图比较；这个对齐用于本地样本回放，没有为运行中的选区增加自动水平移动。

## 修改行为

在原有校验未通过时，新增一条受限的边界补绘路径：

- 候选位置必须向已截范围外扩展，并有足够的有效重叠内容支持位置。
- 变化之前的区域必须是一段与成图边界相连的近似单色空白；已有文字、气泡和图形所在的其余重叠部分必须逐像素一致。
- 空白处后来出现可用的文字或图形纹理时，使用这一帧刷新该空白段，再追加真正超出已截范围的内容。
- 同一帧更新接缝，避免卡片、图片被截成两个不一致的阶段。补绘不依赖前 32px 一定发生变化，边缘仍留有空白也会刷新后方新增内容。
- 已有内容冲突、缺乏稳定参照、只有空白、多个位置冲突等情况继续拒绝。原有重复内容、动画和回访保护保留。

该路径仅处理边界相连的空白，长度最多为半个选区高度且不超过 512px，并要求至少 64px 稳定重叠。一般性的整页重排、已绘制文字改变或大范围动画仍可能暂停匹配；不会任意覆盖已截正文。

## 本机验证

Windows 11、Ryzen 5 9500F、32GB RAM：

- 先按实际图片回放生成完整的 **817×3931px** 已截长图，再接入第二张图。修复后新增顶部 **355px**，刷新边界原空白 **152px**，得到 **817×4286px** 长图，与参考合成结果逐像素一致。
- 同时测试原有气泡内一个像素被改动，以及原图缺少有效参照；这两种输入均被拒绝，已确认内容保持原样。
- 新增向上、向下的边界补绘回归，覆盖“接缝最外侧仍空白，后面的空白段出现了内容”的情况，并检查回访不重复追加。
- 完整拼接离线回归 **52 通过、0 失败**；两个真实桌面采集用例另行通过。此前不等距回滚、错开 20px、拒绝后恢复、分数位移、重复内容保护均覆盖。
- 基础功能回归 **120 通过、0 失败**；五个桌面业务场景另行通过，覆盖采集、预览、鼠标键盘输入和异步导出。受控静态桌面的最终图片与参考逐像素一致。
- 1000×800 选区、77 次更新回放得到 30800px 高度，静态成图逐像素一致；本轮离线处理 P95 为 **10.628ms**、P99 为 **11.631ms**，测试进程工作集增量约 **24.96MiB**。该指标不含桌面采集、显示器呈现或最终导出峰值。

记录位于 `.test-artifacts/native-v0.5.32-*`。实际样本拼接图为 `.test-artifacts/native-v0.5.32-scroll-v2/newly-rendered-boundary-long.png`。用户图片只在本机隔离目录中使用，不进入 Git 或安装包。固定回放通过不等于任意页面都可匹配。

## 安装与回退

- 安装包：`dist/picut-0.5.32-scroll-trial-setup-x64.exe`。
- 便携包：`dist/picut-0.5.32-scroll-trial-win-x64.zip`。
- 工作区入口：`run-scroll-performance-trial.ps1`，静默进入托盘。
- 更新前先从托盘退出当前试验版，释放程序文件和全局热键。安装器不主动结束旧进程。
- 沿用 `%LOCALAPPDATA%/Programs/picut-scroll-performance-trial` 及 `%LOCALAPPDATA%/FloatShot/FloatShotNative-ScrollPerformanceTrial`，保留设置、历史与贴图。
- 回退 v0.5.31：退出新版，启动 `dist/picut-0.5.31-scroll-trial/picut.exe`，或使用保留的 v0.5.31 安装包。
- Astra v0.5.27 入口仍为 `run-scroll-trial.ps1`，正式版仍为 `run.ps1`，两者数据目录与本版独立。

其余范围及安全上限沿用 [v0.5.29 说明](试验版-v0.5.29-流畅滚动.md)，包括 6400 万像素、100000px 高度等限制。本轮仅在上述 Windows 11 机器实测，未进行 Windows 10 实机验证。
