# picut v0.5.14

默认区域录屏热键改为 **Shift+F1**，释放 F2。旧配置中的 F2、早期默认 Ctrl+Alt+R 自动迁移；其他自定义热键保留。新组合已被其他操作占用时退回 Ctrl+Alt+R，两者均占用则停用录屏热键，避免抢占自定义绑定。迁移完成后用户再次主动设置的键位不会重复重置。

设置中的全局热键使用按键录入：点击框后按组合键，单次只记录一个组合，Tab 切换下一项，× 清空并停用。录入期间释放全局热键，保存或取消后恢复，避免按 F1 等键时进入截图。保存前检查不支持的键和重复组合，托盘菜单、工作台按钮及提示随配置更新。

设置、工作台和录屏设置改为参考图中的浅灰背景、白色输入框、深色文字、蓝色选中控件。视频预览外围也改为浅色，视频内容保持原样。

双击 EXE、安装完成后启动、普通快捷方式和重复启动默认只进入托盘，不弹出工作台。需要工作台时使用托盘菜单或双击托盘图标；命令行可传 `--show-home`。原 `--tray` 参数继续兼容。

OCR 文字侧栏去掉顶部标题、灰色操作说明和全选、关闭、缩放及复制按钮，只保留只读文字框和底部“取消”。图片与文字仍同步选中，Ctrl+C 复制，Ctrl+A 全选；缩放、重试等操作可从图片右键菜单使用。取消可在识别过程中终止任务并返回截图或贴图。

## Windows 10 兼容处理

Qt 6.8 的支持基线为 Windows 10 1809（17763）及更新的 x64 系统。安装包最低版本改为 1809，程序声明 Windows 10 兼容性，DPI 初始化改为按可用接口调用。

此前只要 `WDA_EXCLUDEFROMCAPTURE` 不可用就拒绝录屏。现在自动使用兼容模式：区域录屏的边框只画在区域外，控制条放在区域外可容纳的位置；全屏无可用位置时，录制开始后隐藏控制条，通过托盘菜单或已设置的录屏热键暂停、结束。倒计时期间仍显示边框和取消按钮。支持捕获排除的系统继续将控制条放在录制框内。

屏幕采集在 CAPTUREBLT 失败时重试 SRCCOPY。FFmpeg 启动失败会附带系统错误，编码失败保存编码器日志与原始录制目录。启动日志位于原配置目录的 `logs/startup.log`，用于记录 Qt 初始化错误，不记录屏幕图像。

遇到打不开时，可双击安装目录中的 `diagnose.cmd`。它检查系统版本、架构和关键运行文件，在独立临时目录测试启动和一秒纯色视频编码，显示诊断报告路径，不修改个人配置或采集桌面。缺失 DLL、架构不匹配、CPU 不支持指令等加载器错误会分别提示。Win10 具体故障还需要以对应电脑的版本及报告定位，开发机上的模拟回退不能代替真实 Win10 验证。

上一版安装包、便携包和 Git 标签仍保留。当前版本继续使用 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial`，无需迁移个人数据。

## 验证

Windows 11 开发机上，79 项原生回归和 13 项录屏检查通过，无跳过。模拟捕获排除失败的区域、全屏录制已解码检查控制条不进入画面；后续修改重复显示路径后，两个场景再次通过。离线 OCR 的 13 项检查通过，简化界面后又针对真实选字、取消及全屏同步复测通过。

默认启动、重复启动、显式打开工作台、关闭工作台后留在托盘均通过独立进程检查。诊断脚本在 Windows PowerShell 5.1 下通过启动与纯色视频编码检查。安装包在隔离中文目录完成 105 个文件校验、无 SDK 启动、覆盖安装、卸载及个人数据保留检查。Win10 版本门槛和能力回退已修正，实际 Win10 设备仍待复测。
