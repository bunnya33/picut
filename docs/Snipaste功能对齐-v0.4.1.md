# 浮光 FloatShot v0.4.1：Snipaste 功能与操作对齐

日期：2026-10-07。平台：Windows 10/11 x64，Qt 6 Widgets / PySide6。

本项目的截图、标注、贴图以 Snipaste 的免费版和专业版操作为目标；录屏保持原有流程。此版本根据用户提供的 Snipaste 照片重整截图工具分组、就地参数、笔尖预览和标注编辑，**仍不等同于 Snipaste 的完整专业版**。下面按官方功能表列出实际状态，部分实现及未实现项明确标注。

## 运行位置

可执行文件：

```text
D:\UserFiles\Documents\ChatGPT\New project\dist\FloatShot-0.4.1\FloatShot.exe
```

ZIP：`dist/FloatShot-0.4.1-win-x64.zip`。解压后保留整个目录及 `_internal`。更新时先在旧版托盘中选择“退出”，再启动新版；用户设置与历史继续使用原数据目录。

## 操作方式

### 全局入口

| 操作 | 默认方式 |
| --- | --- |
| 截图 | F1 / 托盘左键 |
| 从剪贴板贴图 | F3 / 托盘中键 |
| 隐藏、显示贴图 | Shift+F3 |
| 切换鼠标下贴图穿透；没有贴图时解除全部穿透 | Ctrl+Alt+T |
| 打开工作台 | 托盘双击 |
| 区域录屏 / 暂停 / 停止 | Ctrl+Alt+R / Ctrl+Alt+P / Ctrl+Alt+S |

设置中可修改托盘单击动作、全局快捷键，添加命令快捷键及忽略程序列表。屏幕触发角与 Win+拖拽截图默认关闭，需在“鼠标与命令”中开启。右键动作设置为菜单时，可以进入设置和退出。

### 截图

F1 → 左键拖拽或单击检测区域 → 底部工具栏就地标注 → 复制、保存、贴图。截图开始前冻结桌面，导出内容来自快照。

| 操作 | 方式 |
| --- | --- |
| 复制截图 | Enter / Ctrl+C / 双击选区（选择工具状态） |
| 保存 / 快速保存 | Ctrl+S / Ctrl+Shift+S；Shift+点击保存 |
| 贴图 | Ctrl+T / 中键点击选区 |
| 取消 | Esc / 非编辑状态右键；有标注时确认，可关闭提示 |
| 正在拖拽时移动选区 | 按住 Space，移动鼠标；松开 Space 继续框选 |
| 调整选区 | 八个圆形控制点；“更多 → 其他工具 → 移动 / 调整截图选区”下拖动内部；移动/缩放过程中实时刷新框内预览 |
| 当前屏幕 / 全屏 | Ctrl+A；再次按下切换到所有屏幕 |
| 捕获的鼠标指针 | ` / ! 在冻结快照中显示或隐藏 |
| 微调选区 | 方向键移动；Ctrl+方向键扩大；Shift+方向键缩小 |
| 光标逐物理像素移动 | W / A / S / D |
| 输入尺寸、固定比例、圆角 | 点击选区尺寸标签，或“更多”菜单 |
| 上次选区 / 历史回放 | R / `,` 与 `.` |
| 刷新桌面 | F5，保留当前标注 |
| 白板、透明画板、恢复桌面 | “更多 → 画板” |
| 取色 | C 复制；Shift 切换 RGB/HEX；Alt 召唤放大镜 |
| 文字识别、扫码、输出边框阴影、发送到应用 | “更多”菜单 |

激活其他程序窗口时退出截图可在设置中关闭。手动保存取消后返回原选区。延时、截图包含鼠标、取样范围、取消截图也保存历史均在设置中配置。截图取色放大镜固定无网格，细边框、半透明黑色信息区，蓝色十字的宽度等于一个放大像素，中心像素保留原色。坐标在颜色值上方，C/Shift 操作提示分两行显示；截图初始显示 RGB，Shift 切换 HEX。网格开关仅用于录屏选区放大镜。

**DPI 差异：** W/A/S/D 已使用 Windows 物理坐标移动光标；选区边界仍以 Qt 逻辑整数坐标表示。尺寸对话框提供 px/dip 换算，非整数缩放时会四舍五入，高 DPI 下选区微调尚未达到逐物理像素精度。

### 标注

截图与贴图使用同款工具栏，在图片附近直接调整参数。主栏有七个标注工具组；“更多 → 其他工具”提供选区移动、自由选择对象、序号和放大镜标注。

| 快捷键 | 主工具组 | 就地参数 |
| --- | --- | --- |
| Ctrl+1 | 形状 | 矩形 / 椭圆、线条样式、颜色 |
| Ctrl+2 | 线条 / 箭头 | 图形预览下拉选择直线、开放 / 实心 / 空心菱形 / 圆点箭头、折线；箭头方向和线条样式 |
| Ctrl+3 / B | 画笔 | 粗细圆点、当前色、两排色板 |
| Ctrl+4 | 记号笔 | 笔画 / 矩形 / 椭圆模式、颜色 |
| Ctrl+5 | 马赛克 / 模糊 | 区域形状、处理类型、独立强度滑条；隐藏颜色栏 |
| Ctrl+6 / T | 文本 | 粗体 B、斜体 I、描边 A、字体、字号、颜色 |
| Ctrl+7 | 橡皮擦 | 笔画 / 矩形 / 椭圆模式 |

主栏工具和操作按钮悬停显示快捷键。Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做、Esc 退出、Ctrl+T 贴图、Ctrl+S 保存、Ctrl+Shift+S 快速保存、Enter / Ctrl+C 复制、F10 打开更多。贴图标注中 Space 完成编辑；主栏的贴图按钮也用于完成编辑。

| 操作 | 方式 |
| --- | --- |
| 调整粗细 | 在截图上滚动滚轮或按 1/2；子栏最左侧圆点显示当前粗细，单击展开滑条和预设笔尖 |
| 修改最近标注 | 每次绘制完成自动选中最近对象，调整粗细同步修改尚未确认的对象；点击空白或开始下一笔后确认；Ctrl+Z 可撤销 |
| 画笔预览 | 截图区域随鼠标显示当前颜色和实际宽度的圆形笔尖；按下绘制时隐藏，松开恢复；线条工具也提供笔尖反馈 |
| 形状光标 | 矩形、椭圆使用十字光标，拖动绘制时持续显示 |
| 矩形 / 椭圆控制点 | 自动显示四角、四边中点和上方旋转点，共 9 点；拖边中点修改对应方向尺寸，四角调整两轴，上方点旋转 |
| 右键 | 取消当前标注选中，保留当前绘图工具；折线草稿右键完成 |
| 切换直线与箭头 | Tab |
| 折线 | 逐点单击；Enter 或右键完成；再次 Enter 输出 |
| 约束形状、线条 | Shift：正方形、圆、水平/垂直/45°；缩放形状时 Shift 保持原比例 |
| 输入文字 | 单击显示选区内输入框；Ctrl+Enter 完成；Esc 取消；输入时 B/T 正常录入，Ctrl+A 选择文字 |
| 再编辑文字 | 双击当前尚未确认的文字；字体、粗体、斜体和字号参与导出与对象持久化 |
| 移动标注 | 仅当前尚未确认的对象；中空形状只能拖动实际绘制边缘，内部空白用于确认对象。边缘显示四方向箭头，控制点显示对应缩放/旋转光标。“自由选择标注”仅保留当前待确认对象，不重新选择已确认对象 |
| 删除 / 克隆 / 对象复制粘贴 | Delete / Ctrl+拖动 / Ctrl+Shift+C 与 Ctrl+Shift+V |
| 自定义颜色与透明度 | 单击大色块；色板按钮上滚轮调整 Alpha |
| 色板排序 / 导入导出 | 拖色块排序；子栏末端“高级参数与色板”中导入导出 |
| 高级参数 | 子栏末端小菜单就地展开角度、圆角、文字背景/描边、序号起点、放大倍数和 1–5 个笔尖预设 |

完成绘制后，仅最近一个尚未确认对象可调整参数或拖动。点击非绘制像素（含选区外空白）、开始下一笔、切换绘图工具、右键取消选择或撤销后，控制点与编辑边框消失，旧对象不可重新选择编辑；仍可撤销/重做。子栏调整粗细、颜色等参数不会确认当前对象；下一次绘制使用当前参数。马赛克/模糊强度与粗细分离，区域为笔画时粗细只改变笔画覆盖范围。文字工具滚轮调整字号。

绘图期间自动放大镜收起，线条和画笔工具闲置时显示笔尖预览；按住 Alt 可以召唤取色放大镜。选区调整或形状、文字工具闲置时仍可自动显示放大镜。左下帮助随工具变化，空间不足时收紧显示。

工具栏、帮助、笔尖预览、控制点和取色放大镜都不进入导出图片。贴图重启恢复保留原图和已完成标注对象；旧版对象继续读取，旧马赛克/模糊的强度按原粗细换算。普通 PNG/JPEG/WebP 导出为位图，撤销历史只保留在本次运行中。

### 贴图

| 操作 | 方式 |
| --- | --- |
| 移动 / 吸附其他贴图 | 拖动 / Shift+拖动 |
| 缩放 | 滚轮、+/-、拖边缘；右键输入尺寸或比例 |
| 透明度 | Ctrl+滚轮、Ctrl+ +/-；支持多选批量调整 |
| 旋转 / 水平、垂直镜像 / 灰度 | 1、2 / 3、4 / 5 |
| 恢复 100% 大小及不透明 | 中键单击，同时退出缩略图 |
| 就地标注 / 完成标注 | Space / Space |
| 固定缩略图 / 自由区域缩略图 | Shift+双击 / 右键框选区域 |
| 裁剪 | 右键“裁剪贴图”，再左键框选；Esc 取消 |
| 多选 | Ctrl+点击贴图；随后拖动或调透明度 |
| Solo | 右键“Solo”，再次选择恢复其他贴图 |
| 关闭，可恢复 | Esc / 双击 / Ctrl+W；F3 或托盘恢复 |
| 永久销毁该贴图 | Shift+Esc / 右键销毁 |
| 放大镜 / 取色 | Alt / 放大镜显示时 C；Shift 切换颜色格式 |
| 反色、置顶开关、背景、分组、颜色卡片、OCR/扫码 | 右键菜单 |

F3 支持图片、图片文件、纯文字、HTML、HEX/RGB 颜色。复制图片文件后第一次贴图显示图片，再次贴图可显示路径文字；非图像文件显示路径文字。相同剪贴板内容有已关闭贴图时优先恢复，默认保留 1 张可恢复贴图。网页图片支持剪贴板图片、图片 URL/HTML 图片来源，以及拖入已有贴图；下载失败时提示，不依赖云端图像处理。

背景提供透明、伪透明、暗色棋盘、亮色棋盘。透明模式使用 Alpha 输入区域，透明部分不可点击；伪透明模式可拖动透明部分。开启标注时恢复完整输入区域，方便绘图。

托盘“贴图分组”用于切换、新建和管理。管理可拖动排序、重命名和删除分组；删除分组将贴图移入默认分组。关闭与隐藏分别保存，Solo 不销毁其他贴图。裁剪、旋转/镜像、在灰度或缩略图上开始标注会生成新的原图，已有对象在这些变换时可能被合并为位图。

## 录屏

区域/单屏录制 → 原准备窗口 → 原倒计时 → 原浮动控制条 → 暂停/继续/停止 → MP4 预览、另存、复制视频文件。帧率、画质、系统声、麦克风、独立静音、鼠标指针、声音探测保持原实现。此版本没有修改 `recorder.py`，新增截图快捷操作在录屏选区中被隔离。

## 命令示例

```powershell
.\FloatShot.exe --command "snip"
.\FloatShot.exe --command "snip --last -o clipboard"
.\FloatShot.exe --command "snip --active -o pin"
.\FloatShot.exe --command "snip --region 100 100 800 600 -o file"
.\FloatShot.exe --command "snip --full --delay 2 -o clipboard"
.\FloatShot.exe --command "snip --last --send 0"
.\FloatShot.exe --command "paste"
.\FloatShot.exe --command "toggle"
```

`--region` 使用桌面逻辑坐标。`--file` 指定图片文件路径，路径含空格时在命令字符串内正确加引号。`--group` 选择贴图组。已运行时命令发送给本应用单实例。快捷键命令采用同一格式。支持 `home`、`history`、`settings`、`restore` 和 `through`。命令集专用于截图贴图，录屏按既有快捷键操作。
