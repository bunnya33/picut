# picut v0.5.45：取色记忆与贴图恢复

- 截图取色按 Shift 切换 HEX / RGB 后，下一次截图及重启程序继续使用上一次选择。默认仍为 RGB，按住 Shift 的自动重复事件不会反复切换格式。
- 右键系统托盘，打开“恢复穿透贴图”，通过缩略图、编号和尺寸找到目标贴图并恢复操作。恢复后可正常移动、右键或按 Esc 关闭。也可选择“解除所有贴图鼠标穿透”。
- 原有穿透快捷键保留：默认 Ctrl+Alt+T，鼠标放在目标贴图上时切换，可在设置修改。贴图右键菜单显示当前快捷键，并说明恢复入口。
- 普通截图的像素均不透明，因此不再显示“透明区域背景”菜单。只在图片实际含透明像素时显示；例如从剪贴板贴出带透明通道的 PNG。
- “透明”让下方桌面从图片透明区域透出；“暗色棋盘”“亮色棋盘”便于看清透明边缘。背景只改变显示，不改变复制、保存的图片内容。调整整个贴图窗口的透明度与此独立。
- 移除效果重复的“伪透明”选项，旧布局自动按“透明”恢复。

本次只检查取色格式、穿透恢复、贴图菜单和透明背景显示，不运行未改动的 OCR、翻译、滚动截屏和录屏回归。

验证结果：4 项定向检查通过；另在 Windows 原生平台验证了穿透窗口恢复时系统鼠标穿透标志的移除。包含单独恢复、全部恢复、旧菜单项指向的贴图已销毁、背景不进入导出图片等场景。

安装包：`dist/picut-0.5.45-setup-x64.exe`。免安装包：`dist/picut-0.5.45-win-x64.zip`。更新前从托盘退出旧版，保留整个程序目录。v0.5.44 程序、安装包和源码标签继续保留，可退出新版后运行旧版回退。
