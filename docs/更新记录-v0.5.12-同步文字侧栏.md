# v0.5.12 同步文字侧栏

截图或贴图中按 F4，或从工具栏/菜单选择文字识别，即可进入原图与只读文字并排的无标题栏界面。旧的文字识别全文弹窗已替换。

## 选字与复制

- 左侧拖选原图中的文字，侧栏对应内容同步高亮，并滚动到选区末端。
- 右侧拖选文字，原图对应字符同步高亮；放大时，预览自动平移到所选文字的位置。
- 两边切换焦点后都保留高亮。支持部分数字、标点、跨行与反向选择。
- Ctrl+C 复制选中，Ctrl+A 全选。底部另有复制选中、复制全文、重试。
- 侧栏只读，不支持修改识别结果。Esc、F4 或右上角 × 返回原来的截图/贴图。

## 自动布局与查看原图

普通选区优先保留图片在屏幕上的原位置。右侧够放则侧栏在右边，右边不足而左边够放则放到左边。图片过大、超出当前屏幕可用区域、全屏或两侧都放不下时，进入当前屏幕内的分栏预览。侧栏默认 360 个逻辑像素宽，分栏时可拖动分隔线调整宽度；图片保持比例。

图片区域滚轮缩放，空格+拖动或鼠标中键拖动平移。适应窗口显示全图，100% 按图像原始像素与屏幕像素比例查看，Ctrl+0 也可适应窗口。收起文字侧栏后可用更大区域查看图片，通过右上角按钮展开。侧栏自己的滚轮滚动文字。

布局、缩放与高亮只影响临时识别预览。OCR 始终接收原始分辨率的图像；原截图选区、贴图位置和缩放、标注、保存图像以及 F3 贴图位置均不因预览操作而改变。负坐标的副屏布局也按所在屏幕的可用区域计算。

## 模型、缓存与设置

继续使用本机 PaddleOCR Small，语言组和 CPU/显卡设置沿用。现在文字识别统一使用能提供位置数据的 Paddle 后端；设置中显示固定的识别器名称，Windows OCR 仅保留在质量对照与底层辅助代码中。没有新增服务器连接。

同一界面的图像像素、语言组与运算设备未变化时，重新进入可复用完成的识别结果。重试、改变图片或相关设置会重新识别。退出、隐藏或关闭拥有该预览的窗口会取消正在进行的 OCR 并清理临时文件。

识别准确率、字符位置估计和复杂分栏阅读顺序的限制与 v0.5.11 相同；此次改动不承诺改善 OCR 模型准确率。很长的选区无法同时全部放入放大后的图片视口时，优先显示选区末端。

## 版本与验证

完整程序在 `dist/FloatShot-Native-0.5.12/`，根目录 `run-image-text-trial.ps1` 指向此版。`run.ps1` 仍指向 v0.5.10。v0.5.10 和 v0.5.11 的程序、ZIP 与 Git 标签保留，回退见“版本回滚.md”。试用数据仍放在 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial`。

自动验证覆盖双向选择、只读、复制、焦点高亮、长文本滚动、左右布局、全屏分栏、分隔线、图片缩放和平移、侧栏收起、原图与原位置不变、缓存、取消、销毁、真实 OCR 及 Windows 界面。完整回归为 70 项原生测试、13 项 OCR 测试和 10 项录屏测试通过，均无失败或跳过。

便携包在移除开发 SDK 路径后再次通过 70 项原生测试和 13 项 OCR 测试；Windows 平台的侧栏专项 10 项、真实 OCR 专项 5 项通过。便携程序启动和 F3 合成验证也通过：90 条历史记录、5 次贴图首绘约 34～52 ms，均保持截取位置，且首绘无需等待图片写盘。此计时为合成用例，不代表所有机器与真实截图的耗时。包内附测试报告与合成原图的真实 OCR 预览。
