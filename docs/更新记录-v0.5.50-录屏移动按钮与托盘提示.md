# picut v0.5.50：录屏移动按钮与托盘提示

- 区域录屏的移动按钮置于控制条最左侧，位于原有控制条拖动柄之前；图标改为实心黑色四向箭头。按钮尺寸与拖动录屏区域的行为保持一致。
- 托盘图标使用 Windows 原生悬停提示，显示三行：`picut 版本号`、`截图快捷键：当前组合键`、`贴图快捷键：当前组合键`。修改快捷键后同步刷新；停用的快捷键显示“未设置”。
- v0.5.49 的区域效果切换、动态工具栏、60fps/原画默认设置及长图贴图位置保留。

本次仅构建相关目标，复用录屏区域拖动与托盘快捷键的定向检查并查看按钮预览，不录制桌面，也不运行 OCR、翻译、长截图、视频编码的完整回归。

验证结果：原生程序及相关检查目标编译通过。Windows 原生界面的录屏区域拖动检查（捕获排除与兼容模式）通过，托盘快捷键随设置更新的既有检查通过；两组报告分别为 4 项和 3 项通过，无失败或跳过。已查看录屏控制条预览，确认移动按钮最左且为实心黑色四向箭头。

安装包 `dist/picut-0.5.50-setup-x64.exe`，免安装包 `dist/picut-0.5.50-win-x64.zip`。更新前退出旧版；v0.5.49 程序、安装包与源码标签保留。
