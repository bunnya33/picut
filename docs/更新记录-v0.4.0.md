# v0.4.0 截图工具栏与标注交互

交付日期：2026-10-07。根据用户提供的 Snipaste 功能照片和操作补充，更新 Qt 截图与贴图的就地标注。操作说明见 [v0.4 功能文档](Snipaste功能对齐-v0.4.md)。

## 本次变化

- 主栏改为形状、线条/箭头、画笔、记号笔、马赛克/模糊、文字、橡皮擦七组，对应 Ctrl+1～7；画笔 B、文字 T。序号、放大镜标注、对象选择和选区移动保留在更多菜单。
- 浅灰主栏与蓝色选中状态；选区使用蓝色细线和圆形控制点，尺寸标签只显示像素尺寸。
- 常用类型与样式在工具专属子栏直接切换，箭头提供图形预览。粗细用圆点与数值展示，单击展开滑条和预设笔尖；高级参数在就地小面板中调节。
- 每次绘制完成自动选中最近标注，滚轮和 1/2 同步修改其粗细；此前对象保持原值，修改可以撤销。文字滚轮调整字号。
- 笔尖随鼠标显示当前颜色与实际宽度，按下绘制时隐藏、松开恢复。矩形/椭圆保留十字光标，完成后显示四角、四边和上方旋转点，共九个点；边中点与四角可调整尺寸。
- 文字新增字体、粗体、斜体，并参与导出、复制对象和贴图持久化；输入文字时 B/T 正常输入，Ctrl+A 选择文字。
- 马赛克/模糊合并入口，新增独立强度滑条并隐藏颜色栏。旧版对象按旧参数恢复处理强度。
- 左下显示随工具变化的帮助，小屏幕收紧；Ctrl+A 设置当前屏幕/全屏，反引号或 ! 切换冻结快照中的鼠标指针。
- 右键取消当前标注选中，保留绘图工具；绘图状态下抑制系统随后产生的上下文菜单。折线草稿保留右键完成。
- 录屏选择界面使用原有工具栏，录制、声音、倒计时、暂停/继续、预览和保存流程保持原有实现；recorder.py 的 SHA256 与本次修改前一致。
- 构建从当前 Python 与 Windows 系统目录解析 DLL，避免其他软件 PATH 中的同名 ICU 等运行库混入便携包。

## 验证

- 68 项自动测试，包括 1×/2× 快照、最近对象粗细同步、撤销重做、笔尖显隐与导出隔离、九点编辑和旋转后的尺寸调整、文字字体持久化、独立处理强度、快照鼠标开关、右键取消和贴图标注。
- 已在解锁的 Windows 桌面通过实际合成显示检查：截图和录屏的拖拽中、松开后选区高亮、边框与外部遮罩均可见；导出不含控件。
- 打包后的主窗口启动、合成截图/贴图流程、本地 OCR/扫码及图片链接 TLS 后端检查全部通过；报告保存在工作区 .test-artifacts/portable-v0.4-*。

实际显示检查使用合成画面。多种显示器缩放比例的人工手感、Win+拖拽、触发角与跨屏吸附仍需后续验收。本版没有重新进行真实声音或长时间录制。
