# 版本保留与回滚

当前稳定版为 v0.5.10。Git 标签 `v0.5.10` 保存该版本的源码基线，图片选字试验在 `codex/image-text-trial` 分支开发。仓库仅在本机使用，未配置远程上传。

试用程序位于 `dist/FloatShot-Native-0.5.11-image-text-trial/`，也可通过 `run-image-text-trial.ps1` 启动。试用版默认数据目录是 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial`，稳定版仍使用 `%LOCALAPPDATA%\FloatShot\FloatShotNative`。两个版本不要同时启动，以免全局热键冲突。试用版不会自动迁移稳定版数据。

## 直接切回稳定程序

退出试用版托盘后，启动 `dist/FloatShot-Native-0.5.10/FloatShotNative.exe`，或者运行根目录 `run.ps1`。请保留完整程序目录。稳定版的 ZIP 与 SHA256 文件同样位于 `dist/`。

## 查看与恢复源码

`git log --oneline --decorate --all` 查看版本，`git diff v0.5.10` 查看试验改动。工作区没有未提交修改时，`git switch main` 返回稳定版分支，`git switch codex/image-text-trial` 返回试验分支。需要保留未提交修改时先提交或暂存，避免强制覆盖。

## 额外备份

`backups/v0.5.10-before-image-text-20261016-143159/` 保留初始化 Git 前的完整源码 ZIP、v0.5.10 便携程序 ZIP、SHA256 及校验清单 `manifest.json`。备份、构建产物、依赖、测试输出和虚拟环境不纳入 Git；源码、图标、文档、测试与构建脚本纳入 Git。
