## 直接切回稳定程序

退出试用版托盘后，启动 `dist/FloatShot-Native-0.5.10/FloatShotNative.exe`。请保留完整程序目录。稳定版的 ZIP 与 SHA256 文件同样位于 `dist/`。根目录 `run.ps1` 已改为启动最新 picut。

## 查看与恢复源码

`git log --oneline --decorate --all` 查看版本，`git diff v0.5.10` 查看试验改动。工作区没有未提交修改时，`git switch main` 返回稳定版分支，`git switch codex/image-text-trial` 返回 v0.5.12，`git switch codex/picut-recording` 返回最新开发分支。需要保留未提交修改时先提交或暂存，避免强制覆盖。
