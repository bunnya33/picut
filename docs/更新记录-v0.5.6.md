# 浮光 v0.5.6：普通画笔、马克笔和菜单快捷键

本版调整截图编辑与贴图编辑的标注操作，并把菜单快捷键提示放到右侧单独一列。

## 普通画笔

每笔直接保留鼠标经过的轨迹，抬起后固定，不显示该笔的尺寸框、旋转锚点或调整控制点。继续在已有笔迹上落笔会开始新的一笔；需要移除旧笔可撤销。

滚轮、1/2 键和笔尖粗细选择都只设置下一笔的粗细。在按住鼠标绘制期间，粗细调整被忽略；已经完成的笔迹不会被改粗或缩放。旧画笔设置里的旋转值和区域形状会在选择画笔时归一化，轨迹绘制也不再使用随首尾点变化的旋转中心。

## 马克笔

仅保留“画笔（直线）”和“方框”两种样式。旧的椭圆工具偏好会改用直线；颜色、粗细及合法的方框偏好继续记忆。

直线样式只使用起点、终点，半透明色条和圆形端头参照提供的图片。鼠标途经的弯曲路径不会被记录。画完后只有两个端点控制点，可拖动端点、拖动已着色的线段、调整粗细；按住 Shift 绘制或调整端点可约束到 45° 的倍数。点击未绘制区域或开始下一笔后，旧标注确认固定。

方框保持半透明填充，可使用形状控制点调整。移除的椭圆选项仅影响马克笔，马赛克、模糊和橡皮擦原有区域样式保持。

截图编辑和浮动贴图编辑使用相同规则；鼠标抬起的位置也会作为最终采样点，避免最后一次移动事件缺失时终点滞后。

## 菜单快捷键

托盘菜单、贴图右键菜单和标注菜单把已有快捷键显示在右侧。托盘截图、贴图、显示/隐藏贴图、鼠标穿透、区域录屏、暂停/继续和结束录屏显示设置中实际配置的键；修改快捷键后菜单提示同步更新。未配置快捷键的功能不显示提示。

标注菜单提供 Ctrl+1～7 的工具提示及 Ctrl+Z / Ctrl+Y 的撤销、重做提示。菜单显示使用现有按键处理，不重复注册一份热键。

## 验证

新增检查覆盖普通画笔采样位置与绘制中粗细锁定、落笔在旧笔迹时的行为、撤销、马克笔直线与两端调整、粗线边缘拖动、确认后的固定、方框控制点及样式记忆、Shift 约束、缩放贴图上的绘制、菜单自定义键位与菜单截图。

界面预览来自合成图和实际控件绘制，位于 `.test-artifacts/native-v0.5.6-annotation-ui/`，发布包的 `annotation-previews/` 也保留一份。F3 后台保存的改进继续保留，OCR 仍为 v0.5.4 起使用的 PP-OCRv6 Small。

实测结果：原生 31 项、离线 OCR 11 项、录屏 10 项全部通过，未跳过；仅包含 Windows 系统目录的 PATH 下，便携原生检查 31 项全部通过。最终发布程序的 F3 合成检查也通过：工作台隐藏时读取历史图片 0 次，五次贴图原位置一致，五张贴图保存完成。界面预览已检查普通画笔、马克笔两种样式及菜单右侧快捷键列。

## 运行

先用旧版托盘菜单退出旧版，再启动 `dist/FloatShot-Native-0.5.6/FloatShotNative.exe`，或者运行根目录 `run.ps1`。请保留整个程序目录。
