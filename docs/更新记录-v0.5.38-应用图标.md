# picut v0.5.38：应用图标

应用图标改为用户提供的青蛙剪刀图片。原始图片保留为 `assets/picut-icon-source.jpg`，去除外部黑色背景、保留深色轮廓后导出透明背景的 `assets/picut.png`，并生成 16、20、24、32、40、48、64、96、128、256 像素的 Windows ICO。

程序 EXE、桌面快捷方式、系统托盘、窗口及安装包统一使用新图标。托盘和窗口从内嵌资源读取，不依赖外部图片文件。`tools/make-picut-icon.ps1` 使用透明 PNG 重新生成 ICO，避免重新生成旧的四格图标。

运行 `run.ps1`，安装包 `dist/picut-0.5.38-setup-x64.exe`，免安装包 `dist/picut-0.5.38-win-x64.zip`。更新前退出旧版托盘。v0.5.37 的程序、安装包、便携包和源码标签保留，设置和历史继续沿用。

本次只修改图标和版本信息，沿用 v0.5.37 的截图、工具栏、长截图、录屏、OCR 和翻译实现。上版完整翻译回归的超时及取消状态问题未在本次修复，详见 `更新记录-v0.5.37-工具栏动效.md`。

已验证 ICO 的 10 种尺寸和透明边缘，EXE 中的 10 帧图标与生成的 ICO 逐字节一致；Windows 原生 UI 验证通过，程序实际加载的内嵌图标正确。本次未重新运行完整功能回归。
