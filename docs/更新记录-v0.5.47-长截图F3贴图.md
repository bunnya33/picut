# picut v0.5.47：长截图 F3 贴图

- 在长截图过程中按 F3，结束滚动截取，将当前完整长图直接贴到屏幕上。长截图工具栏也增加“完成并贴图 · F3”按钮。
- F3 优先完成当前长图，不再从隐藏的普通截图窗口导出最初选区；使用自定义全局贴图快捷键时，也会进入当前长图的完成流程。
- 复用长图现有完成流程，等待已经采集的待处理帧结束后输出完整图像；重复按键不会重复导出。
- 贴图保留长图原始像素。初始显示从原选区左上角等比缩小以适应剩余屏幕空间，不拉伸、不裁掉长图；仍可用滚轮缩放和拖动移动。
- Enter 完成并复制、Esc 取消返回截图、保存和继续标注操作保留。

本次仅验证长图完成、F3 路由、工具栏贴图和原有剪贴板贴图衔接，不运行未改动的识别模型、翻译、滚动匹配算法和录屏完整回归。

定向检查通过：全局 F3、界面 F3、工具栏贴图、只有首帧时贴图、取消长截图，以及两种原有剪贴板贴图流程。检查完整长图像素、显示比例、位置及屏幕范围；共 7 个业务用例通过。
