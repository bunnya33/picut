# picut v0.5.27 长截图试验版

基于 Astra 极高方案的新长截图试验，源码分支为 `codex/scroll-capture-v2`。v0.5.26 正式版、主分支和原程序包继续保留；本版用于对比体验，尚未合入主分支。

## 试用

先从旧版托盘退出，以释放 F1 / F3 等快捷键。安装 `dist/picut-0.5.27-scroll-trial-setup-x64.exe`，或解压便携包后运行目录里的 `picut.exe`，也可以运行 `run-scroll-trial.ps1`。默认静默进入托盘。

F1 框选需要滚动的正文区域，在截图工具栏点击“滚动截屏”，手动滚动页面，观察旁边的长图预览；结束时可复制、保存或继续标注。首版优先验证静态网页、文档、代码和聊天历史，请将固定侧栏和输入框放在选区外。若出现内容未接上的提示，往回滚动到已捕获内容，再继续。

试验版使用独立的安装身份和 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ScrollV2Trial` 配置、历史与贴图目录，不覆盖正式版数据。退出试验版后，通过 `run.ps1` 或 `dist/picut-0.5.26/picut.exe` 可恢复正式版。

## 本版变化

由 GPT-6 Astra（极高思考）按最小需求实现独立拼接引擎，旧引擎保留在源码中供对照。采集和匹配分别在后台工作；优先使用 DXGI Desktop Duplication，初始化失败或一直拿不到首帧时退回 GDI，并在日志中记录实际后端。

每个画面先定位到已经截取的文档坐标，只有确认连续重叠才向上下两端补充内容。回看已截内容不会重复追加；已经确认的原图像素保持不变，避免后来出现的相似图案覆盖中间内容。发生缺口或位置不确定时保留结果，往回滚动到已经截取的正文可以重新连接。预览随长图增长自动缩小，橙色框表示最近一次确认的视口位置。

原始图片条带缓存在临时目录，并使用有上限的内存缓存。首版只开放手动纵向滚动，保留完成复制、保存、继续标注和取消操作。

## 验证与边界

长截图专项 25 项通过、0 失败、1 项实屏检查跳过。离线测试核对段落、代码、静态聊天记录、段落间留白、细小及大步滚动、双向补图、跨已截位置回看、缺口后回滚恢复的导出原像素。另用 Chrome 独立渲染的 6 个滚动位置与整页参考逐像素比较，输出一致；这项验证不经过 Windows 桌面抓屏。额外检查重复内容的歧义、轻微亮度变化、内容变化后保留旧图，以及后台匹配与预览的衔接。

Native 功能回归 120 项通过、0 失败、4 项实屏检查跳过；翻译回归 21 项通过、2 项可选参考图跳过；OCR 回归 13 项通过。

当前验证机器桌面处于锁屏状态，真实采集看到的是锁屏画面，无法完成解锁桌面中的网页滚动检查。DXGI 的真实页面采集表现及 Windows 10 实机效果尚未验证；离线测试结果不代表实际页面成功率。

本版优先用于静态正文。固定标题栏、侧栏、输入区、滚动条请尽量放在选区外；动态表情、视频、页面重新排版、重复行和大面积纯空白仍可能使定位被拒绝。快速滚动若跨过了所有可用重叠，需往回滚动补接。完成时只导出已经确认的连续部分。实时采集选区需位于同一显示器内；长图上限为 6400 万像素或 10 万像素高度，先到者为准。

总体设计见 [Astra 方案](长截图重做-Astra方案.md)。
