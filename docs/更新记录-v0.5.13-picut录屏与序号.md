# picut v0.5.13

软件显示名称改为 picut，主程序为 `picut.exe`。图标采用参考图的四个方格，依次为蓝 #4D90FE、黄 #FFC700、红 #E94242、绿 #80C342，提供 16～256 像素的 ICO，托盘和窗口使用相同图案。

## 录屏

- F2 默认进入区域录屏。旧默认 Ctrl+Alt+R 自动改为 F2；用户自定义录屏键保留，其他已占用 F2 的自定义动作优先，避免新增冲突。
- 选定区域后，工具栏为“设置、开始录制、取消”三个图标，使用与截图工具栏相同的浅灰背景、蓝色细边框、32 像素按钮和 16 像素图标。
- 区域录屏点击开始或按 Enter 直接使用已保存参数，不再自动弹设置。需要修改时先点齿轮，保存后继续选择，取消设置不会覆盖原参数。
- 托盘的“整屏录制”仍自动弹设置，确认后开始。帧率、画质、系统声音、麦克风及设备、指针、倒计时均保存到本机。
- 选区左下方显示当前设置摘要；与工具栏重叠时错行，屏幕下方空间不足时移到选区左下方内侧。移动、缩放选区时实时跟随。
- 选择录屏区域时不显示放大取色面板。
- 倒计时阶段就显示所选区域边框，并显示可取消的控制条；Esc 或 × 取消，取消后不会开始录制。开始后沿用该边框，控制条显示时间、暂停/继续和结束，并采用统一的图标工具栏样式。
- 录屏边框、倒计时和控制条继续使用 Windows 捕获排除，支持全屏时控制条位于边框内部。

## 序号文字

Ctrl+8 选择序号工具。点击生成实心圆圈数字，不再显示调整方框和控制点。圆圈仍可通过参数栏调整大小和颜色，序号自动递增。

刚放置序号后按 Tab，在圆圈右侧进入透明行内输入，并显示连接线和下划线。文字颜色和字号跟随该序号，线长随输入内容变化。点击文字外部或按 Enter 确认；该次外部点击只确认当前文字，不会意外添加一个序号。没有文字或只有空白时仅保留圆圈，去掉连接线。Esc 取消本次文字输入，保留圆圈。

文本和圆圈作为同一标注保存、复制和贴图，撤销/重做以整个序号标注为单位；缩放后的贴图也使用原始图像坐标。普通文字工具继续保留原有的行内编辑控制。

## 启动与回退

运行 `dist/picut-0.5.13/picut.exe`，或根目录 `run.ps1`。`run-image-text-trial.ps1` 同样指向新版。完整便携包为 `dist/picut-0.5.13-win-x64.zip`，请解压整个目录。

继续使用原试用版的数据目录 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial`，沿用现有设置和历史。旧版程序目录、ZIP 和标签均保留，退出新版后可以直接运行 v0.5.12 或更早版本，详见“版本回滚.md”。
