# picut v0.5.35：画笔与箭头光标

画笔、箭头及其线段样式使用当前标注颜色的圆点，外围为上、下、左、右四段短十字线，中心与短线之间留出间隙。圆点直径对应笔触粗细，细笔时以短十字为主要视觉提示，粗笔时能直观看到圆点增大。细白色描边帮助光标在深浅背景上保持可见。

截图与贴图编辑共用此样式；圆点随原图到显示区域的比例变化，兼容贴图缩放和高 DPI 屏幕。按下鼠标绘制时隐藏这套预览，松开后在可绘制位置恢复；悬停已选图形的控制点或线条时，继续显示对应的调整或移动光标。预览仅绘制在编辑界面，不写入截图、复制内容或录屏标注。

F1 截图与录屏切换、标注随视频合成、长截图、OCR 和翻译沿用 v0.5.34，完整操作参见 [v0.5.34 说明](更新记录-v0.5.34-截图录屏整合.md)。

程序默认静默启动。更新前先退出旧版托盘，再安装 `dist/picut-0.5.35-setup-x64.exe`。设置、历史和贴图继续沿用现有目录；旧版 v0.5.34 程序、安装包及源码标签保留，可退出新版后直接回退。

验证使用隔离数据与合成图像，手动查看 `--verify-ui` 在 100% 和 150% 缩放下生成的 1px、4px、16px 光标预览。现有画笔绘制、滚轮粗细、Shift 直线、端点调整和贴图缩放相关回归共 28 项通过，Windows 11 桌面补测 5 项通过，无失败或跳过。未修改长截图匹配和 OCR／翻译模型。
