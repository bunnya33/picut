# v0.5.11 图片选字试用版

试验目标：识别后直接在原截图或贴图上选择文字并复制，保留原图、行距和排版，不把图替换成可编辑文字。

## 使用

1. 从旧版托盘菜单退出程序，释放 F1/F3 等全局热键。
2. 运行 `dist/FloatShot-Native-0.5.11-image-text-trial/FloatShotNative.exe`，或根目录的 `run-image-text-trial.ps1`。
3. F1 选定截图后按 F4，或点击新增的图片选字图标；贴图上同样可以按 F4，也可在右键菜单进入。
4. 等待离线 OCR 完成。在原图上按住鼠标拖选文字，Ctrl+C 复制选中部分，Ctrl+A 全选。双击可选词，Shift 点击可扩展选区。
5. Esc、F4 或控制条的 × 退出选字，返回原截图或贴图。选字模式中的其他标注快捷键暂停，避免误画或误关闭。

控制条提供全选、复制、全文、重试和退出，识别时显示阶段与耗时。“全文”可查看和修正文字；修改只用于全文复制，不改变原图或字符坐标。原先的“文字识别”窗口和识别器选择保留。

## 行为与实现

- 用现有 PaddleOCR Small 本机识别，沿用语言组与 CPU/显卡设置，无服务器。图片选字固定用能返回字符位置的 Paddle 后端，设置为 Windows OCR 时也一样；旧全文窗口仍可选择 Windows OCR。
- 识别器返回原图坐标中的文字行和字符四边形。字符边界根据 CTC 模型输出的位置估计，支持中英文宽度差异、数字与标点，允许只复制 `.49` 或日期的某几位。
- 鼠标在文字上呈 I 形，识别文字有浅蓝底，所选字符有较深的蓝色高亮。高亮仅显示在界面上，不写入图片，不改变标注或导出内容。
- 同一界面保留一份已完成的结果。同图、同语言组和运算设置再次进入可直接选字；图像像素或这些设置变化会重新识别，“重试”也会重新识别。不新增识别结果磁盘缓存。
- 贴图选字支持原有滚轮缩放，选区与图像同步缩放。截图/贴图标注过程中进入选字时隐藏标注工具栏，退出恢复。隐藏或关闭窗口时取消识别并清理临时文件。
- 主工具栏新增一个选字入口；原 Ctrl+1～8 标注次序保留。F4 是当前窗口的快捷键，不额外注册全局键位。F1/F3 和录屏逻辑沿用稳定版。

## 已知限制

OCR 的识别质量和耗时仍受 Small 模型、字大小、清晰度和文字行数影响。新选字方式不会把错误识别自动变正确，也不代表达到微信的速度或效果。字符位置是模型对齐的估计，字距很小、花体、复杂斜排和弯曲文字可能有偏差。

全文复制按视觉行从上到下、同一行从左到右排列；同一行多个检测块用制表符连接，换行用换行符。当前没有专门的表格结构、分栏阅读顺序和复杂双向文字解析。现有模型的语言覆盖限制见 v0.5.4 更新记录。旧格式只有整行坐标时只能整行选择。

退出后关闭窗口可释放该界面的图像和选字缓存。未完成的识别会取消，完整结果的缓存只存在当前界面的内存中。

## 稳定版与回滚

稳定版源码基线为 Git 提交 `2b81b38`、分支 `main`、标签 `v0.5.10`；当前试用在 `codex/image-text-trial` 开发。仓库仅在本机，无远程上传。

`run.ps1` 仍启动 v0.5.10。v0.5.10 的完整目录、ZIP 和额外备份均保留，试用包单独生成。试用版默认数据目录是 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial`，不自动导入旧版设置、历史和贴图。显式设置 `FLOATSHOT_DATA_DIR` 时使用指定目录。回滚操作见“版本回滚.md”。

## 验证

自动验证包括真实 OCR 返回的字符位置、数字部分拖选复制、原图不变、缓存复用与失效、取消清理、贴图缩放、工具栏恢复、旋转回原图坐标、大图分块、CPU/显卡以及原生功能回归。具体结果随包附测试报告；合成样本不能替代用户真实图片验收。

Windows 真实平台另外检查截图/贴图选字和工具栏生命周期。录屏检查覆盖区域、全屏、第二屏的实际成片捕获排除；首轮 10 项通过，最近一轮 9 项通过、全屏成片排除 1 项因 GDI 无法看到测试画布而跳过，以附带报告为准。本次 2560×1440、120 行合成文字样本整次识别约 CPU 5.9 秒、显卡 3.0 秒；8 张中英文样本误识别 1/448 字符，速度和准确率仅代表该机器与测试图片。

便携验证清除开发 SDK 的 PATH 后，使用包内 DLL、插件、模型与 CPU/显卡组件运行原生/OCR 回归，并检查程序启动及 F3 原位置贴图。原生回归 67 项、OCR 12 项通过；Windows 选字交互与销毁中取消另外单独检查。最终包内附测试报告和真实 OCR 的原图/选字预览。
