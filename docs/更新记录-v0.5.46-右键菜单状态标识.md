# picut v0.5.46：右键菜单状态标识

- 贴图右键菜单中的灰度、反色、缩略图、鼠标穿透、置顶和“仅显示此贴图”显示勾选标识。开启时打勾，关闭时取消；每次打开菜单均读取当前状态，也能反映快捷键操作和恢复布局后的状态。
- Solo 更名为“仅显示此贴图”：临时隐藏其他贴图，再次点击显示其他贴图，不删除图片。其他贴图原本有的显示、有的隐藏时，点击后统一隐藏，避免反向切换后仍有其他贴图显示。
- 截图和贴图标注的右键菜单显示当前标注工具；矩形/椭圆、线段/箭头、马赛克/模糊正确归属同组选项，折线单独标识。
- 线条样式菜单标出当前实线、虚线或点线；同组样式和工具互斥选择。
- 文字识别右键菜单的文字面板开关显示展开状态。透明区域背景原有的选择标识保留。
- 复制、保存、识别、关闭等一次性操作不显示开关勾选。

本次仅检查菜单及状态切换，不运行 OCR 模型、翻译、滚动截图和录屏完整回归。安装包与免安装包位于 `dist/picut-0.5.46*`。更新前退出旧版；v0.5.45 程序、安装包与源码标签保留。

已通过现有的菜单定向检查，并查看 Windows + Fusion 样式下的实际菜单渲染，确认开关状态列和默认置顶勾选可见，快捷键提示保留。
