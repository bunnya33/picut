# picut v0.5.36：开机自启动

在“设置 → 常规与存储”增加“开机自启动”，默认勾选。首次运行新版时，旧版未启用的自启动占位值会迁移为开启；之后记住用户保存的选择，关闭后重启或升级不会再次开启。点击取消不改变设置。

普通启动时将带引号的当前程序完整路径及 `--tray` 参数写入 Windows 当前用户的启动项，无需管理员权限。登录后静默进入托盘；关闭该选项并保存会移除启动项。免安装版移动目录后，重新运行一次可更新路径。安装包更新仍使用原 picut 安装目录和现有用户数据。

启动项在首次正常运行时生效；验证、预览及性能测试命令不注册启动项。卸载时只清理仍指向该安装目录的 picut 启动项，不删除用户设置和历史记录。

F1 截图／录屏、长截图、标注光标、OCR 和翻译沿用现有功能。v0.5.35 程序、安装包和源码标签保留；退出新版托盘后可运行 `dist/picut-0.5.35/picut.exe` 回退。Windows 中已经注册的启动项可从新版设置中关闭。

验证：Windows 11 上原生回归 127 项通过，离屏环境跳过 5 项桌面采集用例；另行运行的桌面设置检查 4 项通过。自启动注册测试使用独立 HKCU 测试键，检查真实注册表字符串类型、中文及空格路径、静默参数、路径更新和关闭清理；默认开启、旧设置迁移、保存关闭与取消也已验证。正常用户的启动项在验证前后保持一致，未重启设备进行登录测试。
