# picut v0.5.52：文本标记交互

参照用户提供的 Snipaste 操作视频，调整截图、贴图及录屏标注共用的内嵌文本编辑器。

- 选择文字工具后，截图内显示 I 形插入光标。按下鼠标时，输入竖线以点击位置为中心，文本框向四周留白展开，不再把点击位置当成文本左上角。
- 文本框使用透明背景和细深色边线。三个角用于等比例缩放文字，右上角删除，上方控制点旋转；光标分别显示斜向缩放、手形、旋转箭头。边框显示四向移动光标，内部保留文本选择、输入与中文输入法。
- 拖动、缩放或旋转时收起边框和控制点，抬起后恢复。缩放固定对角位置，旋转固定文本框中心；处理鼠标抬起的最终位置。
- 鼠标离开文本框时收起控制点，靠近时恢复。文本框靠近截图边缘时，控制点可以显示在选区外。
- 字体、字号、加粗、斜体、描边及颜色保留现有工具栏与记忆设置。拖动几何变化在抬起后保存，避免每次移动都写入配置。

验证仅覆盖受影响的文本标记及序号文本交互，不执行完整回归。10 项文本定向用例通过，覆盖中文输入、字体样式记忆、导出一致性、缩放/旋转/移动/删除、三种显示缩放比例、边缘控制点及序号文本；另在 Windows 原生界面通过 4 项落点、光标和拖动用例，确认隐藏控制点后鼠标抓取仍保持，松开后释放。以上数量不包含初始化及清理。

v0.5.51 程序、安装包及源码标签保留。

安装包：`dist/picut-0.5.52-setup-x64.exe`；免安装包：`dist/picut-0.5.52-win-x64.zip`。
