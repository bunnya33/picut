# picut Windows 安装包

当前安装包：`dist/picut-0.5.15-setup-x64.exe`。新增滚动截屏，入口位于框选工具栏的文字识别旁边。

双击运行中文安装向导，选择安装位置后安装即可。默认位置是 `%LOCALAPPDATA%\Programs\picut`，无需管理员权限。系统要求为 Windows 10 1809（内部版本 17763）或更新版本，支持 x64 程序。

安装包已经包含 Qt、VC 运行库、录屏组件和离线 OCR 模型，安装过程无需联网下载依赖。安装后可从开始菜单启动，也可在安装时勾选创建桌面快捷方式。安装完成页可选择立即启动。

更新前先通过托盘菜单退出正在运行的 picut，再运行安装包。安装包使用固定应用标识，后续版本可安装到相同目录。

卸载入口为 Windows 设置中的“应用”列表。卸载会移除安装的程序文件和快捷方式，保留个人设置、截图历史和已保存的图片、视频。当前版本继续使用 `%LOCALAPPDATA%\FloatShot\FloatShotNative-ImageTextTrial` 保存配置及历史，与便携版一致。

便携包 `dist/picut-0.5.15-win-x64.zip` 同时提供，可用于免安装运行。v0.5.14 的安装包、便携包和源码标签保留。

旧版安装包把最低版本设成了 Windows 10 2004，会拦截 1809、1903、1909。本版已修正到 Qt 6.8 支持的 1809 基线；更早的 Win10 和 32 位 Windows 不属于当前包的支持范围。Win10 原机安装仍待复测，当前开发机验证不能替代对应设备的测试。

启动默认仅常驻托盘，默认区域录屏为 Shift+F1。安装失败时，安装器在 %TEMP% 下保留 Setup Log 开头的日志；程序打不开或不能录制时运行安装目录的 diagnose.cmd，报告写入独立临时目录，不采集桌面或修改个人配置。v0.5.13 的安装包和便携包继续保留。

## 重新构建

在项目根目录运行：

```powershell
# 如需重新部署当前版本，先运行这一条；已有完整运行目录可跳过。
./native/package.ps1 -SkipBuild
./native/build-installer.ps1
```

首次构建自动将官方 Inno Setup 6.7.3 编译器以便携模式准备到 `build/installer-tools/`，校验下载文件的 SHA-256 和数字签名，中文语言文件也按固定版本和 SHA-256 校验。不会全局安装编译器。

输出安装 EXE 及同名 `.sha256` 文件。`build/installer/` 中保留本次安装内容和逐文件校验清单。安装包版本读取自 `picut.exe`；不需要修改或重新编译应用代码。
