# picut v0.5.53：控制点图标

旧版文本控制图标由截图提取，透明区域残留了不透明的灰黑像素。本版改用 QPainter 在透明背景上直接绘制三个缩放角点和右上角删除按钮，保留 14 像素按钮图标尺寸与蓝白配色，并提供多种 DPI 分辨率。

文字、形状、马克笔区域、马赛克、模糊等标注的旋转控制点统一为单圈箭头，沿用现有蓝色与白色描边，便于在浅色和深色截图上辨认。旋转鼠标光标沿用系统光标的黑白配色，同步采用单圈箭头。

本次只修改图标绘制，保留上一版已确认的文本插入、拖动、缩放、旋转、删除及设置记忆方式。复用文本、矩形、马克笔区域、马赛克和模糊的 5 项定向用例，全部通过；已查看实际界面预览，确认控制图标边缘干净、旋转图标统一。不做完整回归。

v0.5.52 程序、安装包及源码标签保留。新包：`dist/picut-0.5.53-setup-x64.exe` 和 `dist/picut-0.5.53-win-x64.zip`。
