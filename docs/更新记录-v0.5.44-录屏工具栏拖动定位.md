# picut v0.5.44：录屏工具栏拖动定位

- 拖动录制框时，工具栏保持拖动开始时的相对位置，不再逐帧切换框内、框外或上下位置。
- 工具栏靠近屏幕边缘时限制在可见范围；往回拖动可以恢复原来的相对位置，不累计位置偏差。
- 鼠标松开后再判断框外空间。上方有空间时优先放回上方，不足时再寻找下方等可用位置。
- 旧系统无法排除工具栏捕获时，拖动期间保持框外偏移，允许临时超出显示器边缘；松手后重新安排到可用位置。
- 只运行工具栏拖动、外部空间定位及手动拖动工具栏的检查，不重跑 OCR、翻译和视频编码流程。
