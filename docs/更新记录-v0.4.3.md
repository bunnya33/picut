# v0.4.3 截图转贴图保留原位置

交付日期：2026-10-09。修复截图时按 F3 后，贴图默认移动到屏幕中心的问题。

## 本次变化

- 将截图选区的全局位置和显示大小传递到贴图创建流程。贴图在首次显示前完成定位，图像与原截图区域对齐。
- 图像显示大小保持原选区大小，不套用剪贴板贴图的屏幕 70% 适配规则；按实际截图像素数计算缩放比例，适用于高 DPI 与副屏坐标。
- 贴图窗口自身的 2 px 边框位于图像外侧，避免图像出现偏移。截图启用输出阴影时，额外边距向原区域外扩展，原图像保持对齐。
- F3、Ctrl+T、中键和工具栏“贴图”共用原位置输出规则。截图外的剪贴板贴图保持现有居中/适配逻辑。
- 现有置顶、标注、历史、位置持久化、线段端点编辑和录屏流程继续沿用。
