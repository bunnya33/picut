# 浮光 v0.5.8：文字行内编辑与文字参数栏

选择文字工具后，在截图区域内点击即可直接输入。取消原来的固定大小、半透明白底输入框，改为透明背景的行内编辑：边框随内容增长，保留底图，支持中文输入法、多行文字及选择、复制、粘贴等原生文字操作。截图编辑和浮动贴图编辑共用此实现，缩放贴图时输入位置、字号及导出坐标保持一致。

编辑框参考提供的图片，显示三个角落缩放按钮、右上角删除按钮及顶部旋转按钮。拖动文字框边缘移动；拖动角落缩放并同步字号；顶部按钮旋转，按 Shift 以 15 度为步长。文本输入状态下滚轮调整字号。

文字参数栏从左到右为 **加粗 B、斜体 I、描边 A、字体、字号、自定义颜色、两行常用色板**，文字工具不显示笔尖粗细按钮。字号使用可输入的下拉框，以磅为单位，支持 `8.75` 等小数；旧版字号参数继续兼容，保持原有文字大小。字体、字号、加粗、斜体、描边、颜色的调整会即时更新正在输入的文字，并记忆到下一次使用。描边默认采用与文字亮度相反的黑色或白色。

编辑时 Enter 换行，Ctrl+Enter 确认；点击空白确认当前文字并开始下一处输入，切换工具也会确认。Esc 或右上角 × 丢弃当前输入。F3、保存和工具快捷键在行内编辑状态继续生效，导出前先提交文字；浮动贴图的复制和保存同样保留待提交的文字。

文字编辑控件与导出使用相同的文本排版、字体、颜色和描边规则。编辑边框、按钮及光标不导出到截图。普通画笔、马克笔、录屏和 PP-OCRv6 Small 功能继续保留。

本轮原生 38 项、OCR 11 项检查全部通过，无跳过。录屏控制相关 7 项通过，区域、全屏和第二屏的 3 项真实成片捕获排除检查因当前桌面合成器未向 GDI 显示测试画面而跳过，本轮未重新验证实际成片排除。仅保留 Windows 系统 PATH 的便携环境中，38 项原生回归及发布程序 F3 检查也通过。新增检查覆盖中文输入、透明背景、换行、小数字号和格式记忆、编辑与导出文字渲染一致、文字框缩放旋转移动删除、取消输入、缩放贴图、空白确认及导出待提交文字。已检查实际控件生成的界面预览，发布包的 `annotation-previews/` 中保留一份。

先从托盘退出旧版，再启动 `dist/FloatShot-Native-0.5.8/FloatShotNative.exe`，或运行根目录 `run.ps1`。请保留整个程序目录。
