# 浮光 v0.5.9：图标参数栏和圆圈序号

按本次提供的 Snipaste 参考图调整标注参数栏：浅灰背景、蓝色细边框和选中背景，统一按钮、分隔线、两行色板。主工具栏新增序号按钮，原有前七个快捷键保持不变。

- **形状**：粗细圆点、独立填充开关、矩形、椭圆、自定义颜色和两行色板。选择形状和填充直接点击图标，无文字下拉框。填充关闭时只描边，打开时填充内部；空心形状仅绘制边缘可拖动，实心形状内部也可拖动。填充可即时修改最近未确认的形状，支持撤销和参数记忆，旧数据默认空心。
- **线条/箭头**：粗细圆点、图示样式菜单、方向切换、颜色。保留直线、渐细、实心和空心箭头以及正向、反向、双向。箭头和直线仍使用两个端点编辑。
- **普通画笔**：粗细圆点和颜色。每笔完成即固定，不加尺寸框；粗细仅影响下一笔。
- **马克笔**：数字显示实际笔尖直径，纹理方框按钮切换方框/直线，色块以棋盘底展示半透明效果。仍只保留直线和方框两种模式。
- **马赛克/模糊**：数字粗细、区域图标、效果图标、强度滑块和数值。点击已选区域按钮返回画笔模式；原有椭圆区域也保留为直接点选按钮。
- **橡皮擦**：数字粗细和区域按钮，不显示颜色。区域规则同上。
- **文字**：保留行内透明编辑，以及加粗、斜体、描边、字体、小数字号和颜色参数。
- **序号**：主工具栏第八个按钮（Ctrl+8），在点击位置绘制彩色圆圈及白色数字；连续点击自动递增，每张新截图从1开始。可修改最近一个的大小和颜色，数字本身保持不变；撤销/重做后根据现有序号继续编号。大小和颜色会记忆，菜单右侧显示快捷键。截图和贴图标注共用此工具栏。

粗细圆点或数字按钮可打开滑块；滚轮以及1/2键继续生效。工具之间切换时，参数栏按实际内容收缩，避免遗留空白。主工具按钮记住本次选用的矩形/椭圆、线条/箭头、马赛克/模糊子类型。
