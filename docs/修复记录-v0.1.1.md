# 浮光 FloatShot v0.1.1 修复记录

日期：2026-10-06。

## 区域框选显示

区域截图和区域录屏共用的选区窗口此前调用 Windows `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，将整块选区界面标记为防捕获。在远程桌面或屏幕共享通过捕获画面显示桌面的场景，遮罩、选区边框及工具栏可能因此不可见。

v0.1.1 移除了选区窗口的防捕获设置。框选期间显示青绿色边框、原亮度的选区内容及变暗的外部区域；松开后保留选区并显示操作工具栏。截图仍从显示选区窗口之前取得的桌面快照裁切，选区边框及遮罩不会进入导出的图片。

## 验证

- 全部自动化测试 **21 项通过**。
- 新增截图／录屏两种模式的绘制回归测试，检查拖动中和松开后的高亮、边框、外部遮罩、工具栏以及导出图像。
- 新增 `tools/verify_selection.py`，用于在已解锁 Windows 桌面上通过屏幕捕获检查真实显示及窗口捕获属性。
- Windows 原生窗口属性检查通过：截图／录屏选区的显示亲和性均为 `WDA_NONE`（0）。两种模式拖动中和松开后的 Qt 绘制及无边框导出检查通过。
- 修复版 EXE 独立启动及界面渲染检查通过。
- 当前测试机处于 Windows 锁屏状态，真实桌面合成画面的显示验证待解锁后执行。`--render-only` 检查只验证窗口属性及 Qt 绘制，报告明确标记未检查桌面合成画面。

## 更新

通过旧版托盘菜单“退出”关闭旧进程，然后运行 `dist/FloatShot-0.1.1/FloatShot.exe`。设置及历史记录仍使用原数据目录。新版放在独立目录，避免覆盖运行中的旧版程序。
