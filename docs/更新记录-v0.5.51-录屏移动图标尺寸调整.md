# picut v0.5.51：录屏移动图标尺寸调整

录屏移动图标由 16×16 放大到 20×20 逻辑像素。四个实心黑色箭头向外分布，拉开相邻箭头的间隙，避免在小尺寸下看起来连在一起。按钮保持 32×32，位于录屏控制条最左侧。

本次仅构建相关目标，复用录屏区域拖动检查生成按钮预览并核对显示，不录制桌面、不运行完整回归。托盘悬停提示及其他功能保留。

验证结果：原生程序及录屏界面检查目标编译通过，所选定向检查 3 项通过、无失败或跳过。已将 Windows 界面预览与 v0.5.50 对照，确认图标放大、相邻箭头间隙清楚，控制条布局保持一致。

安装包 `dist/picut-0.5.51-setup-x64.exe`，免安装包 `dist/picut-0.5.51-win-x64.zip`。更新前退出旧版；v0.5.50 程序、安装包与源码标签保留。
