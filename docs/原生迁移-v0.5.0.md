# 浮光原生版 v0.5.0

已将主要运行程序改为 **C++20 + Qt 6.8.3 Widgets**。发布包不包含 Python、PySide6、Shiboken 或 `.pyd`，截图、标注、贴图、热键、配置、OCR/扫码和录屏控制均由 C++ 实现。构建与打包使用 CMake、MSVC 和 PowerShell。

## 运行与数据

打开 `dist/FloatShot-Native-0.5.0/FloatShotNative.exe`，或解压同名 ZIP。请保留整个目录。先从旧版托盘菜单退出旧版，以释放 F1/F3 等热键，再运行原生版。

新数据目录为 `%LOCALAPPDATA%\FloatShot\FloatShotNative`。首次启动检测到旧版 `%LOCALAPPDATA%\FloatShot\FloatShot` 时，复制设置、历史缓存、贴图及布局，修正历史中的缓存路径；用户另存的图片、视频路径保持原值。旧版数据保留，旧版开机启动设置不自动替换。指定 `FLOATSHOT_DATA_DIR` 的隔离测试不会自动导入真实数据。

| 标注编辑 | 滚轮调粗细并修改最近未确认对象；笔尖预览；九个形状控制点、两个线段端点；只有实际描绘处可拖动，空白点击或新一笔确认旧对象；Ctrl 拖动克隆；撤销/重做 |
| 参数 | 颜色、线型、粗细、字体等保存；默认 RGB(255,0,4)；Esc 提示居中于截图选区；操作通知默认关闭，可在设置开启 |

主程序空闲时不加载播放器，不创建录屏采集线程，也不启动 FFmpeg。播放器在首次打开视频时加载 `NativeVideoPreview.dll` 和 Qt Multimedia。退出截图立即释放快照和编辑图；撤销只保存标注数据，避免为每一步保存整张位图。

## 验证与内存

源代码构建及独立部署环境均为 **19 passed / 0 failed / 0 skipped**（QtTest 统计包含初始化和清理）。包括真实 Windows OCR、生成后识别二维码、鼠标操作控制点、选区实时刷新、选区中心退出提示、数据迁移、PNG/JPEG/WebP 编码与读取、连续两次 MP4 录制、暂停及解码、WASAPI 系统声音轨道与视频预览解码。

独立部署验证使用发布目录内的 Qt/VC/FFmpeg，仅为测试追加 QtTest；清除 SDK/Qt/Python 路径和插件环境变量后测试通过。发布目录本身不含 QtTest、Python/PySide/Shiboken 或 `.pyd`。实际托盘和工作台启动的模块列表也没有 Python 或播放器模块。原生 SDK 下载、编译、测试和打包脚本已实际执行通过。

本机 Windows 11、两块 1920×1080 显示器、100% 缩放、新配置、未恢复历史贴图的测量如下，单位 MiB：

| 状态 | 工作集 | 私有提交量 | 专用工作集 |
| --- | ---: | ---: | ---: |
| 托盘启动，1 秒后采样 | 25.5 | 4.4 | 未单独采样 |
| 打开空工作台，1 秒后采样 | 36.3 | 5.8 | 未单独采样 |
| 截图打开，双屏快照与 1200×700 选区已标注 | 72.6 | 28.9 | 27.5 |
| 完成第 2 次截图并释放编辑窗口 | 50.0 | 6.6 | 4.8 |
| 完成第 20 次截图并释放编辑窗口 | 50.0 | 6.2 | 4.8 |
| 保留两张独立 1200×700 置顶贴图 | 72.4 | 19.7 | 18.2 |
| 销毁两张贴图后 | 59.4 | 6.6 | 5.1 |

连续截图测试采集真实桌面并构造标注，输出回调仅检查，不改剪贴板、不保存桌面像素，也不打开工作台或托盘。因此完成截图后的数值主要用于验证快照释放和内存是否持续增长；日常复制、保存、历史与恢复贴图会有额外占用。该测试从第 2 次到第 20 次的工作集约 50 MiB，未出现每次截图持续累积。两张贴图的测试图为独立分配的白底图，销毁使用永久销毁操作；普通 Esc 关闭会按“可恢复贴图数量”保留图像。

本轮快照及浮层构造约 139～278 ms，平均 252 ms，不包括输出和识别操作。统一物理坐标的多屏使用一次虚拟桌面采集；控件遍历在后台进行。当前采集仍使用 GDI，尚未做到 Snipaste 的全流程性能对齐。

报告保存在 `.test-artifacts/native-build-tests.txt`、`.test-artifacts/native-deployed-tests.txt`、`.test-artifacts/native-v0.5.0-idle-report.json` 和 `.test-artifacts/native-v0.5.0-final-memory-report/desktop-memory-report.json`。发布目录的 `验证报告/` 同样附有副本。

工作集包含当前驻留的共享库等页面，专用工作集只统计进程专用驻留页面；私有提交量不是同一指标。任务管理器的“内存”与“详情”列可能使用不同统计口径，比较 Snipaste 时需选择同一列。截图尺寸、屏幕数量、DPI、已恢复贴图、剪贴板以及视频预览都会影响占用，不能把隔离测试当作所有机器上的固定数值。录屏编码器是额外进程，其内存不包含在主程序空闲值中。

## 原生第一版仍待迁移的部分

本次优先完成可独立运行的原生主程序，尚未与旧版所有扩展功能逐项等价：截图中 `,`/`.` 历史回放、尺寸/比例锁定及圆角白板；标注对象剪贴板、部分高级文字背景/描边及额外箭头端头、多笔尖和色板管理；贴图裁剪、边缘拖拽缩放、多选/分组与吸附、透明像素输入穿透、网页图片下载和拖入；开机启动设置、发送到目标应用、自定义命令行和部分快捷键校验仍待迁移。

准备录屏窗口暂未迁移实时音量表。麦克风采集和双音轨混音已实现，但本机本轮回归只实测了系统声音轨道，尚未做双设备、长时间录制和多种 GPU/DPI 的完整验收。窗口/控件检测不能覆盖所有自绘或受保护界面，仍可手动框选。

源码与构建说明见 `native/README.md`。根目录 `build.ps1` 和 `run.ps1` 已切换到原生版本；旧版脚本另存为 `build-python-legacy.ps1` 和 `run-python-legacy.ps1`，旧版源码和运行包保留，便于对照迁移遗漏。
