# picut v0.5.43：录屏操作栏与点击反馈

## 操作栏

- 优先寻找录制区域外能完整容纳操作栏的空间，先使用录制所在显示器，再考虑其他显示器；通常与边框保留 8 像素间距，紧凑空间允许贴边。
- 上、下、左、右空间分别按完整可用矩形计算，避免狭长空隙被区域拆分误判。区域移动或窗口移动、缩放后重新安排。
- 全屏等没有足够框外空间时继续放到框内，使用捕获排除。旧系统兼容模式沿用框外显示或隐藏控制条的策略。

## 鼠标点击反馈

- 录屏设置新增“鼠标点击反馈”，默认关闭，保存后记住本机选择；取消设置不改变现有值。
- 开启后左键、右键、中键的按下事件在视频中显示约 450 ms 的圆点与扩散圆环，逐渐淡出。反馈与“显示鼠标指针”独立。
- 动画直接合成到录制帧，桌面不显示额外图层，不接管或拦截鼠标输入。关闭时不创建监听线程。
- 使用独立消息线程监听点击，避免逐帧轮询漏掉短暂点击；动画最多同时保留 24 个事件。
- 动画按编码帧的视频时间绘制，包含编码等待后的补帧，避免处理繁忙时圆点在写入视频前过期；暂停时间不计入视频时间。
- 忽略框外、录屏操作栏和暂停期间的点击。点击位置按录制源范围归一化，兼容移动区域、窗口缩放和固定输出视频尺寸；动画限制在视频范围内。

## 验证和发布

- Windows 录屏回归 21 项通过，0 失败、0 跳过，覆盖多显示器实际采集、捕获排除、窗口缩放、实时标记及框外布局。
- 设置和录屏联动在离屏平台检查 8 项通过，隔离桌面输入；倒计时取消恢复在 Windows 独立复核 3 项通过。
- 原生鼠标事件经实际视频编码和解码验证，确认开启时显示并淡出、关闭及暂停时不产生反馈；另刻意让采集停顿 600 ms，验证补帧仍能保留点击动画。
- 报告位于 `.test-artifacts/native-v0.5.43-recording-tests.txt`、`native-v0.5.43-tests.txt` 和 `native-v0.5.43-countdown-isolated.txt`。
