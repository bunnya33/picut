# picut v0.5.42：图标、OCR 批量与录屏启动

## 图标

使用最新提供的黄色青蛙原图，保存在 `assets/picut-icon-source.png`。仅移除与外围连通的灰白棋盘格背景，保留腹部和眼睛高光。透明 PNG 居中保持比例；Windows ICO 包含 16、20、24、32、40、48、64、96、128、256 像素，统一用于 EXE、托盘、窗口、快捷方式和安装包。

## OCR

- 模型权重和语种保持不变，沿用 PP-OCRv6 small、方向分类与字符位置。
- CPU 服务从单行改为最多 4 行一批，与 GPU 一致。相近宽度文字分组并限制单批总宽度，避免一条长文字放大其他行的填充开销。
- 保留 v0.5.41 的共享内存传图、模型复用、F1 异步预热和空闲 30 秒释放。
- 同机合成图的前置对比中，20 行文字的识别环节从约 2.0–2.2 秒降到 1.2–1.4 秒，整张图从约 3.0–3.1 秒降到 2.5–2.7 秒。108 行密集文字未获得稳定提速。这些是样本测量，不代表所有设备或图片的收益。

## 录屏准备

- 先显示录屏边框与“准备中”，再在下一次事件循环准备输出路径和初始标记，准备完成后开始所设倒计时。倒计时为 0 时，准备完成直接开始。
- 完整标记工具栏在首次点击“标记”时创建，减少开录前不必要的控件初始化。
- 准备中和倒计时均可按 Esc 或点击取消；取消后不会由滞后的回调继续录制，并恢复原截图、选区和标记。
- 开始准备录屏时释放闲置 OCR 模型，不中断实际进行中的识别；已切换录屏时不再触发 F1 的延时预热。
- 日志记录反馈显示、输出准备、标记准备及总准备时间，便于检查不同电脑的等待位置。

## 验证与使用

测试记录位于 `.test-artifacts/native-v0.5.42-*`，包括 OCR 批量文字/字符位置、录屏准备取消与重试、标记按需工具栏和捕获排除检查。安装包和便携包发布前核对版本、文件哈希和模型校验值。

- OCR：17 项通过，1 项旧版性能比较因未指定基准目录跳过；另行完成了每批 1、2、4、8 行的同图对比。
- Windows 原生操作：13 项通过；最终录屏启动检查 6 项通过，样本中的边框和准备提示在约 0.07–0.18 秒显示。这不是所有设备的响应保证。
- 实际录制：7 项通过，覆盖时间、暂停、保存、控制条排除、初始标记和录制中更新标记。图片翻译集成 5 项通过。
- 图标：10 帧 ICO 可解码且与 EXE 内资源一致，透明角和浅色/深色小尺寸预览已检查；原生 UI 验证通过。
- 现有 Windows 复制测试遇到 OLE / OpenClipboard 访问失败，重试仍失败；同一选字、复制、缓存测试在 Qt 隔离剪贴板下通过（3 项）。本轮未据此确认 Windows 系统剪贴板的复制行为，原始失败日志保留在测试目录。

安装包：`dist/picut-0.5.42-setup-x64.exe`；免安装包：`dist/picut-0.5.42-win-x64.zip`。运行前退出旧版托盘，沿用已有设置和历史。源码仍位于 `codex/ocr-performance-trial`；v0.5.40、v0.5.41 和主分支保留。
