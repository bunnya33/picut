# 浮光 FloatShot 原生版 v0.5.1

本次增加录屏区域提示与控制条，继续使用 C++20 + Qt Widgets，无 Python 运行时。

## 录屏操作

- 区域录屏开始后，录制区域持续显示红色细边框和四角标记。边框位于录制范围内侧，不阻挡鼠标点击底下的窗口。
- 控制条默认位于录制区域顶部内侧居中，显示录制状态、`HH:MM:SS` 有效录制时长、暂停/继续、结束。拖动左侧抓手、状态或时间可改变位置。
- 暂停期间计时停止，边框变为橙色；继续后恢复红色并接着累计。
- Ctrl+Alt+P 暂停/继续，Ctrl+Alt+S 结束。通过热键改变状态也会同步控制条。
- 控制条能放下时，拖动范围限于录制区域；很小的选区使用所在显示器的可用范围。全屏录制的边框和控制条位于所录屏幕内，不固定在主屏。
- 已开启的系统声音、麦克风仍能分别静音。结束后控制条显示“正在保存”，避免重复点击；保存完成或录制失败后，边框和控制条自动关闭并释放。

## 捕获排除与兼容性

边框和控制条是两个独立的顶层窗口。开始采集前设置并检查 Windows `WDA_EXCLUDEFROMCAPTURE`，显示后再次检查，并等待一次桌面合成刷新。目标行为是视频中显示这些窗口底下的原始画面，不录入控制器，也不留下黑块。

要求 Windows 10 2004 或更新版本的本地桌面会话。若不能设置捕获排除，则关闭边框与控制条、提示原因，不启动录制。此标记用于 FloatShot 使用的 Windows 桌面采集，不能保证外部所有录制软件采用相同的排除机制。

## 本次验证

- 原有原生测试：19 通过、0 失败、0 跳过。
- 新增录屏 UI 测试：7 通过、0 失败、3 跳过。覆盖真实 Qt Windows 窗口上的区域/全屏布局、有效计时、按钮与热键暂停同步、FFmpeg 生成 MP4 并解码、结束与失败关闭窗口、拖动限界、音轨静音按钮存在、极小选区、副屏定位及窗口释放。
- 两个窗口的捕获排除标记均经 Windows 查询确认。
- 独立部署检查：清除开发环境 PATH、Qt 插件变量和 FFmpeg 变量，仅使用发布包内运行库。录屏控制条的五项交互/编码/清理检查全部通过（含测试初始化与清理为 7 通过、0 失败、0 跳过），工作台启动与绘制也通过。该检查使用合成视频源，不包含成片排除验收。
- **尚未完成实际成片排除验收**：当前执行桌面的 GDI 采集没有显示新建的纯色测试窗口，返回旧桌面或黑色画面；诊断中的 DXGI 采集也无法获得正常测试画面。因此区域、主屏全屏、副屏全屏三项实录检查在录制前跳过，不能把系统标记成功当作成片排除通过。
- 包内控制条预览由程序窗口合成到纯色背景，仅展示外观；合成源的视频解码报告仅验证录制流程，不证明捕获排除。

在桌面正常显示的本地会话中运行 `build.ps1`，上述实录检查会先确认纯色测试窗口能被采集，再录制、解码并检查边框与控制条覆盖位置的像素。

## 使用新版

先结束正在进行的录屏，再通过旧版托盘菜单退出旧版，双击本目录的 `FloatShotNative.exe`。项目内当前包路径为 `dist/FloatShot-Native-0.5.1/`，压缩包为 `dist/FloatShot-Native-0.5.1-win-x64.zip`，请保留整个目录中的 DLL、插件与 FFmpeg。

配置和历史仍使用 `%LOCALAPPDATA%\FloatShot\FloatShotNative`。原生 v0.5.0 及旧版包保留。初始原生迁移范围见“原生迁移-v0.5.0.md”。
