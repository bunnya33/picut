# picut v0.5.40：黄色青蛙图标

应用图标更换为用户提供的黄色青蛙截图图案。原图保留为 `assets/picut-icon-source.jpg`，仅移除与外围连通的白色背景，保留腹部、眼睛高光及图案内部白色，导出透明背景的 `assets/picut.png`，居中缩放并保持原比例。

程序 EXE、托盘、窗口、快捷方式和安装器统一使用新图标。Windows ICO 包含 16、20、24、32、40、48、64、96、128、256 像素的图像；Qt 托盘和窗口从内嵌 PNG 资源加载。

已检查浅色、深色背景及小尺寸显示；10 帧 ICO 均可解码、透明角正常，EXE 内的 10 帧资源与 ICO 逐字节一致。Windows 原生 UI 验证通过，实际加载的窗口图标已确认是新图案。

本次仅更新图标、版本及发布说明，其余实现沿用 v0.5.39，不重复运行完整 OCR、翻译、滚动截屏和录屏回归；相关功能验证与限制见 `更新记录-v0.5.39-实时标记录屏.md`。

入口为 `run.ps1`，安装包为 `dist/picut-0.5.40-setup-x64.exe`，便携包为 `dist/picut-0.5.40-win-x64.zip`。更新前退出旧版托盘；v0.5.39 的程序目录、安装包、便携包和源码标签保留，设置及历史继续沿用。
