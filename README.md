# picut · v0.5.29 长截图流畅性试验版

本分支 `codex/scroll-performance-trial` 在 Astra 首版上改进连续跟踪、局部动画处理和采集管线。运行 `run-scroll-performance-trial.ps1` 或 `dist/picut-0.5.29-scroll-trial/picut.exe`，安装包为 `dist/picut-0.5.29-scroll-trial-setup-x64.exe`。本次使用全新的试验配置与安装目录，详见 [试用说明与实测](docs/试验版-v0.5.29-流畅滚动.md)。

`run-scroll-trial.ps1` 继续启动 Astra 首版 v0.5.27，`run.ps1` 继续启动正式版 v0.5.26。旧程序、安装包、数据和 Git 标签保留；切换时先退出旧版托盘，释放全局热键。开发依据见 [长截图流畅性与性能设计](docs/长截图设计-流畅性与性能.md)，其中性能数字是目标，实际结果以本版试用说明为准。

以下为已留存正式版的功能说明。

本地图片翻译已合入 `main`，同时保留 v0.5.25 的滚动截屏修复。画笔（Ctrl+3）按住 Shift 拖动可画任意方向直线，松开后用两个端点调整；普通画笔行为不变。运行 `run.ps1`，默认静默进入托盘。详见 [本版更新](docs/更新记录-v0.5.26-正式翻译与Shift画笔.md)。

修复重复表情导致错位、覆盖中间消息的匹配问题；动态更新保留各区域的真实边界，不把中间空隙并入更新范围。修复极薄条带在预览中出现空白横带的问题。详见 [本版更新](docs/更新记录-v0.5.21-长图内容保护.md)。

滚动截屏现在会刷新已拼长图中可见的动态区域：表情播放或回看已截位置时，预览和最终图片一起更新，高度不变；记住动态块位置用于后续匹配。详见 [本版更新](docs/更新记录-v0.5.20-长图动态刷新.md)。

修复聊天记录中的多个动态表情导致滚动截屏失败：静止播放不再误判为滚动，滚动时用未变化的文字和气泡确认位置，接缝避开检测到的动画区域。详见 [本版更新](docs/更新记录-v0.5.19-动态表情滚动截屏.md)。

滚动截屏改为局部特征匹配与独立线程抓屏，修复段落留白、局部动画及轻微文字重绘被拒绝的问题。支持向上、向下补图和往返回看。详见 [本版更新](docs/更新记录-v0.5.18-滚动拼接重构.md)。

修复截图复制后按 F3 时，新贴图沿用“全部隐藏”状态而不可见的问题。剪贴板图片暂时不可读时会短暂重试，并尝试本地图片文件格式；复制了新内容后取消旧请求。详见 [本版修复](docs/更新记录-v0.5.16-F3贴图修复.md)。

F1 框选后，点击“文字识别”右侧的“滚动截屏”。手动滚动或点 ▶ 自动滚动，旁边实时显示完整长图，超过屏幕高度时等比缩小。拼接检查滚动部分是否贯穿上下边缘，允许一侧固定、另一侧滚动；四周被静止内容包围的内部滚动不会追加成长图。详见 [本版更新](docs/更新记录-v0.5.15-滚动截屏.md)。

运行 `run.ps1` 或 `dist/picut-0.5.26/picut.exe`，完整便携包为 `dist/picut-0.5.26-win-x64.zip`。更新前先从托盘退出旧版，释放全局热键。

Windows 安装包：`dist/picut-0.5.26-setup-x64.exe`。双击打开中文安装向导，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\picut`，可修改安装位置、选择桌面快捷方式；安装与卸载不清除原有设置和截图历史。详见 [安装包说明](docs/安装包说明.md)。

F1 截图、Shift+F1 区域录屏、F3 原位置贴图。录屏选区工具栏提供设置、开始与取消，区域录屏直接使用本机保存的设置；全屏录屏仍先弹设置。选区左下方显示参数摘要，倒计时也显示录制边框，控制条可暂停、结束并显示时长。

Ctrl+8 序号不再显示调整框；刚放置后按 Tab 输入旁边的带下划线说明，点击外部确认，空文本自动去线。软件名称与四格图标已更新。详见 [v0.5.13 更新说明](docs/更新记录-v0.5.13-picut录屏与序号.md)。

F4 的图片与只读文字侧栏继续支持双向同步选字，普通选区自动放在右侧或左侧，全屏时自动分栏。新版本继续使用已验收翻译版的数据目录。所有旧版程序和 Git 标签均保留，见 [版本回滚](docs/版本回滚.md)。

当前默认实现为 **C++20 + Qt 6.8.3 Widgets**。运行、构建和打包均不需要 Python。

直接运行 [picut.exe](dist/picut-0.5.26/picut.exe)，或解压 `dist/picut-0.5.26-win-x64.zip`。请保留整个目录。先用旧版托盘菜单退出旧版，再启动原生版以释放 F1/F3 等热键。

F1 截图，Ctrl+1～8 标注，滚轮调粗细，F3 将截图在原位置变成置顶贴图。Space 编辑贴图；Shift+F1 区域录屏，Ctrl+Alt+P 暂停/继续，Ctrl+Alt+S 停止。颜色和工具参数记忆、选区中心 Esc 提示、默认关闭的操作通知均已迁移。

v0.5.10 修正左侧粗细按钮的模式切换：马克笔、马赛克、模糊、橡皮擦左键直接返回画笔模式，矩形和椭圆左键直接返回空心描边；右键打开粗细滑块。详见 [v0.5.10 更新说明](docs/更新记录-v0.5.10.md)。

v0.5.9 将形状、填充和区域模式改为直接点击的图标按钮，其他标注参数栏统一为紧凑样式；新增形状实心填充，粗细用圆点或数字预览，效果强度显示数值。主工具栏新增“序号”（Ctrl+8），点击生成自动递增的圆圈数字。详见 [v0.5.9 更新说明](docs/更新记录-v0.5.9.md)。

v0.5.8 将文字改为透明行内输入，保留缩放、旋转、删除控制；文字参数栏按参考图排列为加粗、斜体、描边、字体、小数字号和颜色。详见 [v0.5.8 更新说明](docs/更新记录-v0.5.8.md)。

v0.5.7 修复截图和录屏选区工具栏在拖动、缩放时不跟随的问题；主工具栏的图标、浅灰背景、蓝色细边框、尺寸和间距按提供的参考图调整。详见 [v0.5.7 更新说明](docs/更新记录-v0.5.7.md)。

v0.5.6 调整普通画笔为每笔完成后固定，取消画笔控制框；粗细只设置下一笔。马克笔仅保留直线和方框，直线支持两端点和粗细调整。托盘、贴图及标注菜单把快捷键显示在右侧，并跟随自定义键位更新。详见 [v0.5.6 更新说明](docs/更新记录-v0.5.6.md)。

v0.5.5 修复 F3 贴图卡顿：隐藏工作台时不读取历史图片，PNG 和贴图持久化放到后台；移动和缩放只保存布局。90 条历史记录的合成对照中，贴图首次绘制平均从约 6.3 秒降到约 30 ms。详见 [v0.5.5 更新说明](docs/更新记录-v0.5.5.md)。

v0.5.4 的文字检测和识别都改为 **PP-OCRv6 small**，仍覆盖官方声明的 50 种语言；方向分类保留 PP-LCNet x1.0。默认大图使用显卡，小图使用 CPU，显卡失败时自动回退 CPU。当前同机 2560×1440、120 行样本，显卡从 medium 的约 4.9 秒降到 Small 的 2.8 秒，CPU 从 17.9 秒降到 5.5 秒；三份模型权重约从 139 MiB 降到 36 MiB。8 张中英样本 Small 为 1/448 字符错误，不代表整体准确率。详见 [v0.5.4 更新说明](docs/更新记录-v0.5.4.md)。识别按需在独立 C++ 子进程运行，完成/取消后退出，不需要服务器或 Python。旧版 v0.5.3 保留用于完整模型对照；语言体系覆盖限制见 [v0.5.2 更新说明](docs/更新记录-v0.5.2.md)。

录屏区域边框和可拖动控制条显示有效时长，可暂停、继续、结束。全屏录制将控制条放在所录屏幕内部，并启用 Windows 捕获排除。v0.5.8 本轮录屏控制检查 7 项通过，3 项真实成片捕获排除检查因桌面未显示测试画面而跳过；v0.5.7 的区域、全屏和第二屏成片排除曾全部通过。详情见 [v0.5.8 更新说明](docs/更新记录-v0.5.8.md)。

## 开发

安装 Visual Studio C++ 桌面工具、Windows SDK 和 CMake。在项目根目录运行：

```powershell
./native/setup-sdk.ps1
./build.ps1
./run.ps1
```

`build.ps1` 编译当前分支、运行原生测试并打包到 v0.5.29 独立试验目录；首次构建会准备精简的原生 OpenCV 跟踪 SDK。录屏 UI 测试使用真实 Windows 平台，会短暂显示测试边框、控制条和纯色测试画面。启动脚本及 EXE 默认托盘启动，可传 `--show-home` 打开工作台或 `--verify-features` 等参数。详细构建、测试与 SDK 参数见 [native/README.md](native/README.md)。

| 目录/文件 | 内容 |
| --- | --- |
| `native/src/` | C++ 截图、标注、贴图、录屏、OCR/扫码与应用 |
| `native/tests/` | 原生交互与编码回归 |
| `native/CMakeLists.txt` | CMake 项目 |
| `native/setup-sdk.ps1` | 无 Python 的依赖准备与校验 |
| `native/package.ps1` | Qt/VC/FFmpeg 便携包 |
| `docs/原生迁移-v0.5.0.md` | 功能迁移范围与验证结果 |

旧版 Python 源码、测试和发布目录保留作为迁移参考；原生程序不使用它们。旧版说明与脚本为 `README-python-legacy.md`、`build-python-legacy.ps1`、`run-python-legacy.ps1`。第三方说明见 [native/THIRD_PARTY_NOTICES.md](native/THIRD_PARTY_NOTICES.md)。
