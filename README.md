# picut · v0.5.56

C++20 + Qt 6.8.3 的 Windows 截图、标注、贴图与录屏工具，包含离线 OCR、图片翻译和滚动截屏。文字识别使用系统标题栏和左右分栏，左侧显示图片，右侧显示识别结果。可拖动分隔线调整栏宽，关闭后贴图留在左栏图片的位置。

运行 `run.ps1` 或 `dist/picut-0.5.56/picut.exe`，默认静默进入托盘。安装包为 `dist/picut-0.5.56-setup-x64.exe`，免安装包为 `dist/picut-0.5.56-win-x64.zip`。保留整个程序目录，更新前先从托盘退出旧版。

## 截图和录屏

- F1 框选区域，Ctrl+1～8 标注，Enter 复制，F3 在原位置贴图。
- 选区工具栏的摄像机按钮切换为录屏工具栏；返回按钮或 Esc 回到截图，选区和标记保留。倒计时取消也会恢复截图。
- 已完成的箭头、画笔、形状、文字、序号和高亮可以随实时录屏保存；马赛克、模糊等效果处理当前画面。标记固定在选区中的坐标，随区域缩放或调整保持对应关系，不追踪页面上的对象。
- 开录后点击“标记”展开工具栏，绘制和编辑过程实时录入视频；关闭标记工具栏恢复操作桌面。拖动四向箭头按钮可移动采集区域。录制前可切换“窗口录屏”并点击目标窗口；窗口缩放时完整内容按宽、高分别缩放，不补边、不裁切。
- 录屏设置可在开始前主动打开并在本机记忆。Ctrl+Alt+P 暂停 / 继续，Ctrl+Alt+S 结束；边框和控制条显示录制区域与时长。独立的 Shift+F1 录屏热键已移除。
- 录屏操作栏优先使用框外空间。拖动录制区域时保持原来的相对位置，靠近屏幕边缘时限制在可见范围，松手后再重新定位；上方空间恢复时优先回到上方。设置中的“鼠标点击反馈”默认关闭，开启后在视频中显示短暂点击动画。
- 全屏录屏仍可从托盘进入并先打开设置。F4 识别文字，支持原图和只读侧栏同步选字；图片翻译在原文位置显示完整结果。
- 工具栏的滚动截屏支持手动纵向滚动、往返定位和局部动画匹配。请将固定标题栏、输入区与滚动条留在选区之外；变化过大或参照不足时会保留已确认内容并暂停匹配。

## 安装、数据与回退

正式安装目录为 `%LOCALAPPDATA%/Programs/picut`，不需要管理员权限。运行目标为 Windows 10 1809+ x64 及 Windows 11；窗口捕获需要 Windows 10 1903+，录制中编辑标记需要系统支持捕获排除（Windows 10 2004+）。较老系统仍可区域录屏，控制条移到选区外，预先完成的标记仍会合成到视频。实测范围见 [本版说明](docs/更新记录-v0.5.40-黄色青蛙图标.md)。

沿用已验收长截图版本的数据目录 `%LOCALAPPDATA%/FloatShot/FloatShotNative-ScrollPerformanceTrial`，保留最近使用的设置、历史和贴图。旧正式版 v0.5.26 的配置仍留在原目录，不自动合并历史。

`run-scroll-performance-trial.ps1` 保留 v0.5.33，`run-scroll-trial.ps1` 保留 Astra v0.5.27；旧安装包和源码标签均保留，参见 [版本回滚](docs/版本回滚.md)。

## 开发

```powershell
./native/setup-sdk.ps1
./native/build.ps1 -BuildDir build/native-scroll-performance
./build.ps1
./native/build-installer.ps1
./run.ps1
```

`build.ps1` 运行原生、拼接、OCR、翻译、F3 和录屏检查，再打包到 v0.5.56 目录。录屏与桌面采集检查会短暂显示测试窗口。SDK、模型转换和构建依赖留在工作区，发布的程序不携带 Python。
